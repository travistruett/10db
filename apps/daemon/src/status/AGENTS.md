# apps/daemon/src/status

- `status-service.ts` holds the status line's state: sources call `hold(key, …)` while something pauses work and `release(key)` when it lifts, and it keeps each hold pending for 2 minutes before it is shown and shown for 2 minutes after it lifts (`StatusDto`, served by `GET /status`). It runs on the injected clock's timers, so the edges fire with no client poll, and `onChange` (the daemon emits `status.changed`) runs when the shown set or a shown line's words change. `stop()` (called as the daemon stops, after the sources) cancels the timers, so none fires into a closed database. It is memory only: a restart starts every hold again, and a source that still holds says so again.
- A source is a hold that ends by itself and asks the builder nothing: the admission load hold (`load/monitor.ts`), an account waiting for its model list (`accounts/model-list-wait.ts`) and the update's shaping hold (`self-update/self-update.ts`). A source never raises a card for it; one that used to withdraws the cards an earlier run left, once, when it is made. What needs the builder to act stays an Inbox ask.
