# apps/daemon/src/judge

- `judge/` asks a fast model a typed question for a routine decision, through OpenRouter, Anthropic's Messages API or Bedrock's runtime, by the kind of account decisions run on (`ask.ts` dispatches on `ModelQuestion.credential`; `anthropic.ts` and `bedrock.ts` send one structured-output body, `{ choice: enum(options), confidence }`, clamp `confidence` to 0..1 in code, match `choice` to the options ignoring case, and throw `JudgeCallError` on a refusal, `max_tokens` or a malformed answer; Bedrock signs with the account's AWS profile or its bearer token; the OpenRouter paths below apply to an OpenRouter credential only) (`decisions/2026-10-31-openrouter-makes-routine-decisions.md`). `judge.choose` reads the config (`getJudgeConfig`) and the credential of the account decisions run on (`JudgeConfig.accountId`; `createJudgeCredentialReader` in `daemon/judge-services.ts`, injected as `readCredential(accountId)`, a `JudgeCredential`: an OpenRouter or Anthropic key account's own `account:<id>` Keychain item (a Bedrock profile account needs none, a Bedrock token account its item) through `readAccountSecretAsync`, the fingerprint check launches use, so the event loop never waits on `security`; it counts against the 4 s timeout; never cached; no account, an archived or other kind of account, or a missing or changed secret is `no_key`) itself, calls TypeSafe's System One models (`typesafe/*`) on `/api/v1/systemone`, every other model OpenRouter's decision list names on `/api/alpha/decisions`, and any other model on `/api/v1/chat/completions` (`openrouter.ts` cites the shapes; `modelApi` picks; with the list unreadable a model is taken to be a decision model; `decisions/2026-11-13-a-decisions-model-is-picked-from-openrouters-list.md`), parses each response with zod, logs the call to `judge_calls` and never throws: off, no key, a timeout (`JUDGE_TIMEOUT_MS`, 4 s, on the injected clock; it lives in `@10db/contracts` so the Decisions chart's cutoff line is this value), an HTTP error or an unparseable answer is a `fallback` and the caller applies today's rule. A System One or decisions choice's confidence is the chosen option's probability, else its `confidence`, and an answer with neither is a fallback; a chat model's is its own `confidence`. `decision-model-list.ts` reads OpenRouter's decision models (`decision-models.ts` parses them, keyless, `?output_modalities=decisions`) and keeps them 6 hours: a decision never waits for it (routing reads the copy held, or none while the first read runs), an old copy is answered at once and read again behind the caller, and after a failed read none starts for a minute; `GET /judge/models` serves them (409 with the judge off, 502 when unreadable). `PATCH /judge` that changes a decision's model asks the model the test decision with the credential decisions will run on first, and refuses the patch when it can't answer (400; 409 with the judge off). The logged outcome of an answer is provisional (`acted` at or above the floor, else `below_floor`); the decision that acts on it records the real one with `recordJudgeOutcome`. Every secret in the credential is scrubbed from error text and is in no response, event, row or log. `GET/PATCH /judge`, `POST /accounts/:id/test` (one tiny call on that account's default model: 404 unknown, 400 when it can't answer decisions, 409 with the judge off) and `GET /judge/calls` are served by `daemon/judge-services.ts`; `startDaemon` deletes the old `openrouter-api-key` Keychain item (`removeLegacyOpenRouterKey`; with the judge off it is not called); `startDaemon` deletes calls older than 30 days. `Judge.off` is the `TENDB_JUDGE=off` flag: a decision checks it first and makes no `choose` call, so no `fallback_off` row is logged. The sizing service (`sizing/`) asks `task_rigor` and `task_kinds` off the request path, and `services.patchTask` records a builder's change of a judged value as the call's `overridden` outcome, which the Decisions stats count as answered. The runner asks no decision: a task's rigor decides up front whether it is reviewed (`decisions/2026-11-13-each-rigor-sets-its-review-rounds-and-fix.md`). `review_size` stays a `JudgeDecision` value so logged calls keep parsing and keep their label, but it is not in `JudgeConfig.decisions` (`AskedDecision`, `isAskedDecision`): a stored config that still holds it parses with the key dropped, and it is never asked. `test_value` is asked by `test-value/` after an implement step passes, and when a Review starts, never on the request path; it never blocks a step. `fenced` (`fenced-text.ts`) wraps task or diff text a decision shows the model as data.
- `GET /judge/calls/page` (a `JudgeCallsPageQuery`: limit, offset, decision, outcome; 400 for an unknown decision or outcome) answers one page of the call log with the total of the filter, and `GET /judge/decisions` answers each decision's last 30 days (calls, acted, below the floor, shadow, stopped, fallbacks by reason, cost, median latency, the answers); both are served by `daemon/judge-services.ts` over `judgeDecisionStats` and `pageJudgeCalls`. `GET /judge/models` adds each model's cost per million decisions and time per decision with their source, computed per request from the database and returned as a new list, never into the cached one (`decision-model-numbers.ts`: the builder's own mean logged cost and median latency over 30 days, else the model's input price over the builder's typical decision size, a fixed guess when no call can say, and OpenRouter's median latency from the sync's stored speeds).
- Decisions run on an OpenRouter, Anthropic API key or Bedrock account (`decisions/2026-11-21-decisions-run-on-any-api-account.md`; `powersDecisions` in `@10db/contracts`; the store refuses a plan login with `PLAN_LOGIN_CANT_DECIDE`). `PATCH /judge` that changes the account sets every decision to the new account's default model (`daemon/decision-offer.ts`: OpenRouter's `typesafe/jev-1.13`, else the Efficient tier model's launch id from the account's list) unless the patch names models the account lists, and saves nothing unless every resulting model answers the test decision; an account with no model list yet is refused. On Anthropic and Bedrock a decision's model is checked against the account's list; `GET /judge/models` serves that list (with the same cost and time numbers) while Decisions run on such an account, else OpenRouter's. `POST /accounts/:id/test` works for any account that powers decisions, on its default model. The status reports no missing secret for a Bedrock account that signs with an AWS profile. `NO_DECISION_CREDENTIAL` is the no-credential detail. Archiving the Decisions account is refused (`archiveAccount`). The benchmarks sync's key is the Decisions account's when it is OpenRouter, else any live OpenRouter account's. `JudgeService.lastFallback(account)` keeps in memory why the account's latest decision call fell back (a rejected key, an expired profile, a timeout), and the judge status carries it as `account.fallback`, which Settings › Decisions shows as "Decisions are falling back to rules: <reason>". A decision's call is priced from the account's own model list (`account_models` price per million tokens, matched on the launch id); with no listed price the cost is null. The Bedrock client of a profile is kept per profile and region, so the SDK's credential cache outlives a call.
- `outage.ts` watches how each decision's call went (`JudgeDeps.onCallHealth`, wired in `startDaemon` to `createJudgeOutageCard` in `inbox/judge-outage-card.ts`). The first failure of a run logs at warn. A failure that won't clear alone (no key, HTTP 401/402/403, Anthropic's "credit balance is too low", an expired Bedrock sign-in) raises one status card at once; any other needs `OUTAGE_FAILURES` (5) failures in a row, or 10 minutes failing, with no answer between. The card, "10db's judge can't answer", folds under `judge-outage` and names the provider's cause and fix; nothing more is raised while it stays down. It closes after 3 answers in a row, or at once when the judge is switched off (Settings or `TENDB_JUDGE=off`; also once after a start, for a card a stopped daemon left). A cause that may clear alone is not raised again within 30 minutes of closing; a hard one is. A stopped call counts for nothing.
