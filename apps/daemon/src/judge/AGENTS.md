# apps/daemon/src/judge

- `judge/` asks a fast model a typed question through OpenRouter for a routine decision (`decisions/2026-10-31-openrouter-makes-routine-decisions.md`). `judge.choose` reads the config (`getJudgeConfig`) and the key of the OpenRouter account decisions run on (`JudgeConfig.accountId`; `createJudgeKeyReader` in `daemon/judge-services.ts`, injected as `readKey(accountId)`: the account's own `account:<id>` Keychain item through `readAccountSecretAsync`, the fingerprint check launches use, so the event loop never waits on `security`; it counts against the 4 s timeout; never cached; no account, an archived or other kind of account, or a missing or changed secret is `no_key`) itself, calls TypeSafe's System One models (`typesafe/*`) on `/api/v1/systemone` and every other model on `/api/v1/chat/completions` (`openrouter.ts` cites both shapes), parses each response with zod, logs the call to `judge_calls` and never throws: off, no key, a timeout (4 s on the injected clock), an HTTP error or an unparseable answer is a `fallback` and the caller applies today's rule. A System One choice's confidence is the chosen option's probability; a chat model's is its own `confidence`. The logged outcome of an answer is provisional (`acted` at or above the floor, else `below_floor`); the decision that acts on it records the real one with `recordJudgeOutcome`. The key is scrubbed from error text and is in no response, event, row or log. `GET/PATCH /judge`, `POST /accounts/:id/test` (one tiny call with that OpenRouter account's key: 404 unknown, 400 not OpenRouter, 409 with the judge off) and `GET /judge/calls` are served by `daemon/judge-services.ts`; `accounts/openrouter-key-move.ts` moves a key left in the `openrouter-api-key` item into an OpenRouter account once at start (never throws; with the judge off it is not called); `startDaemon` deletes calls older than 30 days. `Judge.off` is the `TENDB_JUDGE=off` flag: a decision checks it first and makes no `choose` call, so no `fallback_off` row is logged. The runner asks the one decision built, review size (`runner/review-size.ts` holds the rules, which force a review with no call for a binary file or a path in a project hazard, a manifest, lockfile, migration, CI or harness file, and the state, which fences the task text and diff as data and carries only "gate passed (exit 0)"; `RunnerOptions.judge` is injected, `offJudge` in `test/engine.ts` keeps today's rule; a cancel or shutdown aborts the call through `ctl.gateAbort`): see `docs/architecture/01-factory-loop.md`.
