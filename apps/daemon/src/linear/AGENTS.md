# apps/daemon/src/linear

- `bindings.ts` (`createLinearBindings`) is a project's Linear binding: the workspace and team a session read through the builder's own sign-in, stored at the app setting `linear.<projectId>` (`LinearBinding`). Link (`POST /projects/:id/integrations/linear/check { teamKey }`) refuses when the project's account has no Linear (`LinearVia.None`, the row's hint) and otherwise opens a visible chat on that account titled "Link Linear team AMP" whose opening message asks the agent to read the workspace with Linear's tools and call 10db's `link_linear_team`. The one check per project is held in memory (a restart drops it); `link_linear_team` writes the binding only from that check's chat, or records a refusal naming the reached workspace when the team is null, then archives the chat shortly after its answer. Unlink is `DELETE /projects/:id/integrations/linear`. `GET /projects/:id/integrations` carries `linear: { binding, check }`.
