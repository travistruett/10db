# apps/desktop/src/conversation

- `src/conversation/` is the conversation kit (sessions spec §8): `Markdown` (the only place streamdown is configured; `docs/architecture/decisions/2026-11-13-agent-output-renders-as-hardened-markdown.md`), `ConversationList` (windowed by article, one per builder message and one per agent turn, a turn longer than `ARTICLE_ROWS` in parts, tail-following with Jump to Latest, over `ConversationEntry`, a view model each screen maps its DTOs to), `ToolCallCard` (rows from `tool-words.ts`, reads and edits folded and subagent calls nested by `conversation-rows.ts`; edits as one `Diff` per hunk beside `hunk-gutter.ts`'s numbers, from the hunk's own starts). A link opens through `openWebLink` (`docs/architecture/decisions/2026-11-13-the-opener-opens-confirmed-https-links.md`). The kit never compares a harness id (ESLint). `e2e/window-csp.spec.ts` draws a Plan fence in WebKit under a script policy with no eval or WebAssembly. `Composer` takes a screen's own controls (`leading`, `actions`, `modelControl`) and Attach's name; Enter sends, Shift+Enter is a new line and Enter picks from an open `@` or `/` list (`isSendKey`); Send is a small ↵ icon and Stop an icon while a turn runs; `DictationButton` starts macOS Dictation through the shell's `start_dictation` command (the `startDictation:` action down the responder chain, no Accessibility permission) and shows only in the desktop shell; `ModelMenu` (model chip, Effort submenu, More models) and `ContextRing` are the shared model and context controls (`model-menu-options.ts` holds their rules); `WorkingLine` takes the turn's start and the screen's words after the line (the Workbench's pass page uses all of them).
