# apps/desktop/src/views/sessions

- Sessions (`/sessions`, sidebar item third after Inbox and Factory; UI spec `docs/superpowers/specs/2026-11-11-10db-sessions-ui.md`, plan `docs/superpowers/plans/2026-11-12-10db-sessions-m5a-sessions.md`) is a global screen whose tabs are chats. `SessionsView` (`sessions-view.tsx`) takes `?chat=<ChatId>` or `?fresh=<id>` (`sessions-search.ts`), reads the open chats (`daemon/chat-queries.ts`) and the fresh tabs the window keeps in `localStorage` (`fresh-tabs.ts`: pure functions over the list), draws the strip through `HeaderSlot` (`shell/header-slot.tsx`; the shell keeps the drag region on its own boxes and the slot's tabs are not part of it; on Sessions the slot starts at 88 px) and the selected tab beneath it. With no tab it opens a fresh one, so the screen is never blank. The views here never compare a harness id (ESLint, as in the kit); the agent's name is `capabilities.label`.
- A fresh tab (`fresh-tab.tsx`) is not a chat until its first `@` or its first send; then exactly one chat is made in the chosen project (`useCreateChat`, one at a time even when an `@` and a send come together), the tab is replaced by it, and its draft moves to the chat's (`session-drafts.ts`: a module store, so a tab switch, a closed tab that returns and a visit to another screen keep the words). A send asked for travels as a request the chat's tab takes once, so a failed post leaves the draft in the chat and the next send goes to the same conversation. `GET /projects/:id/chat-models` says `unavailable` for a ChatGPT-plan project: its words show, Recent and Start from stay, the composer is off.
- A chat's tab (`chat-tab.tsx`) is the session bar (`session-bar.tsx`: title edited in place, the kind line from `kind-line.ts`, model, 40 px context meter with its tooltip, File as Tasks, the ⋯ menu), the conversation in a 720 px column (`chatEntries` over the kit's `itemEntries`: a chat tool call on 10db's server whose result parses as `ChatToolResult` and agrees with its tool becomes a `TaskRow`, with Open on Board and Undo; a judged denial is the kit's own row with Allow This, sending "Go ahead: {title}"), the cards it waits on (`PermissionRequest`) and the composer. A project removed from 10db leaves the transcript and "This project was removed from 10db." with no composer.
