Focuses: mockups

1. Settings › Focuses

A new project section under Planning, after Areas and Hazards. It lists your focuses that apply in every project, then this project's own. Each row's loudness is one click. A project can override one of yours by key (the cyan tag); the row then edits the override, and "Use yours" drops it. The hit rate is the last 30 days; a noisy focus (at least 5 asks, at least 80% answered "Looks right" without a note) turns yellow. Hold is greyed out until S5.

2. The task drawer: For You

The first section of a task's Overview when its diff hits a focus. One fold per focus, its loudness tag, and only the matching hunks. Each file shows the agent's reason (from the build step) and the reviewer's check against your guidance. Folds start open for ask and hold, closed for show. "Open the whole diff" opens the Changes view. The hunks are kept when the run finishes, so a Done task still shows them after its worktree is gone.

3. The Ask card in the Inbox

One card per task, however many ask focuses it hit. It is written when the run moves on, so the task never waits for it. "Looks right" closes it. "Send back with a note" files a follow-up task with your note, as the Acceptance card does. For a focus set to hold (later), a third button, Merge, turns on the PR's auto-merge.
