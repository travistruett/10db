# 10db Accounts in the Daemon and API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every project runs on a known billing account. Each session proves it is that account before it sends a prompt. Projects on different accounts run in parallel under each account's own lane cap and usage limits. A metered account stops starting sessions at its monthly dollar cap. Tokens and dollars are visible per account and per project. Agents can't casually read another account's credentials.

**Architecture:**

- **Data.**
  - A new `accounts` table: kind, label, payer, expected identity, config directory, Keychain secret reference, secret fingerprint, settings, lane cap, monthly cap and `archived`.
  - `projects.account_id` replaces `billing_mode`.
  - `sessions` gains `account_id` and `cached_tokens`, and `cost_usd` becomes null for subscriptions.
  - Usage is a query over sessions. The daemon seeds one "Personal" subscription account on Claude Code's default config directory and makes it the default for new projects.
- **Launch.** `environment/` gains the Keychain module and the **launcher**, the one module that knows the account variable names.
  - It turns an account into a session's launch: the env, the model to request (through the model map) and what the session must report. It reads a keyed account's secret from the Keychain at each start and compares its fingerprint.
  - It also builds the **project env**: the login env with every billing switch stripped. The gate and the repo's MCP servers get that, and never the account's credentials.
- **Verification.** A pure `sessions/account-check.ts` decides whether what Claude Code reports matches the account: `accountInfo()` before the prompt (identity, plus key source and provider), then the key source and model at the first `init`. The real and the fake adapter both use it. Mid-session credential errors are refusals too. A refusal pauses the account, and the workstream waits in `PAUSED_LIMIT`; the workstream doesn't fail.
- **Accounts runtime.** A new `accounts/` daemon module owns:
  - account pauses (replacing provider pauses), keyed by account, with three reasons: usage limit, monthly cap and refused;
  - the monthly cap, checked against the calendar month in local time on the injected clock;
  - the cards and the preparer. The preparer probes an unready account's identity at most once a minute, records the Personal account's current login, and asks the builder to confirm any other;
  - staggered subscription starts;
  - the account service behind the HTTP routes.
- **Scheduling.** The scheduler launches a workstream only when its account is ready, not paused, under its monthly cap and under its lane cap. Within a lane, the runner checks the pause and cap again before every further session.
- **Guard.** In every step kind, agents can't run Keychain commands, can't dump the environment, can't reference a credential variable, and can't touch any path under 10db's data directory.
- **API and UI.** These routes come from accounts spec §7: `GET`/`POST /accounts`, `PATCH /accounts/:id`, `POST /accounts/:id/archive`, `PUT /accounts/:id/secret`, and `GET /accounts/:id/signin`, `/identity` and `/usage`. `PATCH /projects/:id` takes `accountId`. The desktop's new-project form and the Billing section get an account picker. Removing `billingMode` forces both. The Accounts screen itself is the next plan.

**Tech Stack:** As in M2a. No new dependencies: the Keychain is the macOS `security` tool through `node:child_process`, and usage is SQL over `sessions`.

## Decisions made in the plan

The spec leaves these open; the plan decides them. Task 10 records the lasting ones in `docs/architecture/decisions.md`.

1. **Personal lives in Claude Code's default directory.** The seeded "Personal" account has `configDir = null`, meaning Claude Code's default config directory: the builder's current login.
   - The first time work needs it, the preparer probes that directory and records the email it finds as `expectedIdentity`, because that login is "the builder's current login" (spec §3).
   - Every account created through the API gets its own directory under `<dataDir>/accounts/<id>/claude` (mode 700), and its identity is recorded only when the builder confirms it (a card's Confirm, or `PATCH /accounts/:id`).
2. **Keyed identity is a key fingerprint** (spike 12: a gateway reports no organization). `accounts.secret_fingerprint` is `sha256:` plus the first 16 hex digits of the secret's SHA-256.
   - `PUT /accounts/:id/secret` records it.
   - Every session start reads the Keychain secret and compares its fingerprint. A missing secret, or one changed outside 10db, refuses the session.
   - `expectedIdentity` is an optional organization for API-key and Bedrock accounts, compared only when set. A gateway takes none. `secretSet` means a fingerprint is recorded.
3. **Account refusals pause the account, not the workstream.** These problems are the account's, not the work's: identity mismatch, wrong credentials (key source or provider), signed out, secret missing or changed, cannot bill (a billing error or an account on hold) and unconfirmed.
   - The workstream goes to `PAUSED_LIMIT` and keeps its next action. It resumes the conversation when the session had started.
   - The account is paused with reason `refused` until the builder acts: `PATCH`, a new secret, or a card's Confirm or Resume. A Resume that fixed nothing meets the same refusal at the next session, and the card comes back.
   - A model mismatch, a missing `accountInfo()`, and the repo's settings problem still fail the workstream as before (decision 47).
4. **Unready accounts never launch.** A subscription with no confirmed identity, or a keyed account with no secret, is unready. The scheduler leaves its work `QUEUED` and calls the preparer, which raises one card. For a subscription with no identity it first probes, at most once per `PREPARE_RETRY_MS` (60 s) per account.
5. **Model check.** At the first `init`:
   - A requested alias (`^[a-z]+$`) matches a reported model whose ID contains `claude-<alias>`. That covers `claude-haiku-5-5`, a Bedrock `us.anthropic.claude-haiku-…` and a 1M-context suffix.
   - An ID from the model map must equal what is reported.
6. **Usage accounting.**
   - A session's usage belongs to the calendar month (local time) in which the session started.
   - Cached tokens are cache reads. Input is uncached input plus cache creation.
   - `costUsd` is the SDK's cumulative `total_cost_usd` for metered kinds, and null for subscriptions.
7. **Monthly cap.** The scheduler checks it before each launch, and the runner before each further session in a lane (handoff, next step, fix).
   - At or over the cap, the account is paused (`monthly_cap`) until the first instant of the next local month. One card is raised, and its body is rewritten with the spend as each running session ends.
   - Raising the cap, or any save, resumes the account. The next check pauses it again if it is still over.
8. **Pauses.** One pause per account, persisted in `app_settings` as `account_pause.<id>`.
   - A pause with no end (`refused`) outranks one that ends; otherwise the later end wins.
   - Only a usage-limit pause stops the account's running lanes. A cap or refused pause lets running sessions finish.
9. **Staggered subscription starts.** On a subscription account, one session starts at a time: from just before `adapter.start` until the session reports `started` or `ended`. Identity probes take the same slot.
   - This is the spec's fallback while the refresh question is open (spike 12 refresh check: partial).
   - The lane cap default stays 4.
10. **The project env.** The gate, the shipping gate and the expansion of the repo's MCP servers get the project env: the login env with every billing switch and 10db variable stripped, and no account variables. Only a session gets its account's credentials. This amends decision 44.
11. **Stripped from every session.** In addition to today's list: `CLAUDE_CONFIG_DIR` and `CLAUDE_CODE_OAUTH_TOKEN`. A Bedrock session also drops the login shell's `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, `AWS_PROFILE`, `AWS_DEFAULT_PROFILE`, `AWS_REGION` and `AWS_DEFAULT_REGION`. Nothing billing-related comes from the login shell any more, including `AWS_BEARER_TOKEN_BEDROCK` and `ANTHROPIC_BEDROCK_BASE_URL`.
12. **Secret handling.**
    - A secret is 8 to 8192 characters of printable ASCII with no space, quote or backslash.
    - It reaches the Keychain through `security -i` on standard input, never on a command line. It is read back and compared before its fingerprint is recorded.
    - Keychain failures answer 409 with a message that names the item, never the value.
13. **Guard additions** beyond the spec's list:
    - a reference to a credential variable (`$ANTHROPIC_API_KEY`, `${ANTHROPIC_AUTH_TOKEN}`, `$AWS_BEARER_TOKEN_BEDROCK`, `$AWS_SECRET_ACCESS_KEY`, `$AWS_SESSION_TOKEN`, `$CLAUDE_CODE_OAUTH_TOKEN`);
    - `ps` with an environment flag (`-e`, `-E`, or `e` in a BSD-style word);
    - `compgen -e` and `compgen -v`.
14. **Route shapes.**
    - `POST /accounts` answers 201 with `{ account, signIn }`, where `signIn` is null for keyed kinds.
    - `PATCH` is `/accounts/:id`.
    - `GET /accounts/:id/usage` takes `?month=YYYY-MM` and defaults to the current month.
    - `GET /accounts/:id/identity` probes live and answers what Claude Code reports, plus the refusal a session would meet now.
    - `POST /accounts/:id/archive` is refused for the default account and for an account any project uses.
    - `PATCH /projects/:id` with a new `accountId` is refused while the project has unfinished work, because a resumed conversation can't cross config directories.
15. **Account labels are unique.**
16. **Cards.** An account card folds per project on `account:<id>:<reason>`, with the problem appended for a refusal (`account:<id>:refused:<problem>`) and for a readiness card (`account:<id>:<problem>`). Its `detail.accountCard` holds `{ accountId, reason, problem, seenIdentity }`. A refusal card offers Resume ("I fixed it") and Later; one that names a seen subscription identity also offers Confirm. Answers go through the inbox's `onFlagAnswer`.
17. **Protocol.** Removing `billingMode`, `BillingMode` and the `provider.paused`/`provider.resumed` events is a breaking contract change, so `PROTOCOL_VERSION` becomes 3 (Task 9).
18. **`AccountDto`** carries `isDefault` and `secretSet`, and no sign-in command. The command names `CLAUDE_CONFIG_DIR`, which only `environment/` may name. It comes from `GET /accounts/:id/signin` and from `POST /accounts`.
19. **Aliases.** An account's `aliases` filter the profiles the router and escalation consider. A persona's pin and the unmeasured fallback are not filtered: the model check refuses a model the account can't serve.
20. **Identity probe.** `probeAccount` starts Claude Code with no prompt, in the data directory, with no setting sources and no MCP servers. It reads `accountInfo()` within 15 s, then ends the process.
21. **Credential errors mid-session.**
    - `authentication_failed`, `oauth_org_not_allowed` and `cloud_credential_error` are `signed_out`.
    - `billing_error` and `account_on_hold` are `cannot_bill`.
    - Each ends the session as an account refusal (decision 3).
22. **`insertSession` records the project's current account** and derives whether its cost is metered. No caller passes the account.
23. **Claude Code version warning.** The system check warns when the installed `claude` has a higher major version than 2.1.302, the version the account names were verified on (spec §10 point 4).

## Spec amendments needed

The code forces these changes to the accounts spec. Travis decides each one; the plan is written as listed.

1. **§3 and §5, model check timing.** Claude Code emits `init` only after the first prompt is sent, so "the model reported in `init` must equal the requested one" can't run before the prompt. The identity and key-source checks do run before the prompt. A model mismatch stops the session at its first turn, before any tool runs, but that turn's first request may already be billed. Suggested wording for §3: "Any identity or credential mismatch refuses the session before the prompt, and nothing is billed; a model mismatch stops it at its first turn, before any tool runs."
2. **§4, `configDir`.** "It is created by 10db under the data directory" can't hold for the seeded Personal account. The builder's current login lives in Claude Code's default directory. Suggested: "`configDir`: subscription only; null for the seeded Personal account (Claude Code's default directory), otherwise created by 10db under the data directory as `accounts/<acc_id>/claude`, with mode 700."
3. **§4, keyed identity.** Spike 12 found a gateway reports no organization, so keyed accounts need a stored key fingerprint. Add `secretFingerprint` (`sha256:` plus 16 hex digits, never the secret) to `accounts`. State that a gateway's `expectedIdentity` is always null.
4. **§6, "one card".** Inbox cards belong to a project and fold per project, so a cap or pause affecting an account bound to two projects raises one card in each project that meets it. Suggested: "with one card per project that meets it".
5. **§7, route shapes.** `PATCH /accounts` becomes `PATCH /accounts/:id`. `POST /accounts` answers `{ account, signIn }`, because the sign-in command names `CLAUDE_CONFIG_DIR`, which only the launch module may name (§3).
6. **§5 "Signing in", for Personal only.** The plan records Personal's identity from its first probe without a confirmation step. §3 seeds Personal "for the builder's current login", and that login is what the probe reads. Every other subscription account still needs the builder's confirmation. Confirm this reading, or the plan adds a Confirm card for Personal too (Task 6's `confirmCard` already exists; it would be one branch).

## Global Constraints

Everything in M0's, M1a's, M1b's, M2a's and the batch delivery plan's Global Constraints still applies. On top of that:

- **Branch:** `feat/accounts`, cut from `main` once the batch delivery plan and M2b Part A have both merged. Open one PR to `main` at the end; its title is a Conventional Commit. Until Task 5 sessions are checked against the billing mode as before. From Task 5 to Task 6, an account with no confirmed identity runs without the email comparison, and Task 6 makes such an account unready. The branch ships as one PR.
- **Commits:**
  - Each commit is one command that names its paths: `git add <path> … && git commit -m '…'`. Never `git add -A`, `git add .` or `git commit -a`.
  - The scope is one of `daemon`, `desktop`, `contracts`, `db`, `harness`, `repo`, `ci`, `docs`, `deps`. The subject is lowercase and the header is at most 100 characters.
  - Every message ends with this footer, after a blank line, passed as two extra `-m` paragraphs:
    ```
    Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
    Claude-Session: https://claude.ai/code/session_01KFqjacxo6Va8EyHF93n3xr
    ```
  - Run `pnpm format` first. A failing hook leaves the paths staged: fix the cause and rerun the same line. Never `--no-verify` or `LEFTHOOK=0`.
- **Generated files** are regenerated, never edited: `pnpm --filter @10db/contracts generate` after a contracts change; the migration baseline is regenerated after a schema change (Task 2 Step 5 and Task 9 Step 4). Never merge `packages/db/drizzle/` or `packages/contracts/generated/` textually.
- **Contracts are additive until Task 9.** Tasks 1–8 only add schemas, fields and event types. Task 9 removes `billingMode`, `BillingMode` and the provider events and bumps `PROTOCOL_VERSION` to 3.
- **IDs** are minted only through `mintId`. New kind: `Account` (`acc`).
- **Every state change writes its row and its event in one transaction** (`state.write`). `account.saved` on every account insert or change (its data names the changed fields, never a value), `account.paused` and `account.resumed` on pauses, and `account.cap_reached` in the same transaction as a cap pause. The desktop's `INVALIDATIONS` maps `account` (Task 9).
- **Secrets never leave the Keychain except into a session's env.** Not into the database (a fingerprint only), logs, events, cards, API responses, error messages or test output. Logs never carry an email or organization either (decision 47's rule): refusal messages name the account's label and what kind of value differed, and the seen identity travels only in a card's `detail` and body.
- **Only `environment/` names account variables** (`CLAUDE_CONFIG_DIR`, `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `CLAUDE_CODE_USE_BEDROCK`, `AWS_REGION`, `AWS_PROFILE`, `AWS_BEARER_TOKEN_BEDROCK`). Other modules use `SECRET_VARIABLES` and `signInCommand` from it. Two exceptions set no variable:
  - The repo-settings refusal families in `sessions/project-settings.ts` are prefixes, not account variables, and stay where they are.
  - `sessions/account-check.ts` and the fake adapter compare the `apiKeySource` and `tokenSource` values Claude Code reports, which happen to spell variable names.
- **No `as` casts, no `!`, no `any`** except at a validated boundary with a comment (`.claude/rules/code-style.md`). Exhaustive switches over `AccountKind`/`SupportedAccountKind`, `AccountProblem` and `AccountPauseReason`.

## Review Focus

The conditions most likely to bite a person, each with the task whose tests pin it:

1. **A session runs on the wrong payer.**
   - Case: two subscriptions share a Keychain entry, so config directory B reports A's email; the builder re-ran `/login` in `~/.claude` as another account; a client's key was swapped in the Keychain by hand; the login shell exports `ANTHROPIC_API_KEY`, `CLAUDE_CONFIG_DIR` or `CLAUDE_CODE_OAUTH_TOKEN`.
   - No prompt is sent; the account is paused with a card naming what was seen; the work waits in `PAUSED_LIMIT` and resumes after the builder confirms or fixes the account.
   - Tests: Task 3 (`strips every billing switch and 10db variable, and adds no account credential`; the launch refusal row `a secret changed outside 10db`), Task 5 (the `checkAccount` rows `another subscription in the Keychain` and `an API key where the subscription should be`; `pauses the account and sends no prompt when the identity differs, then resumes after Resume`; `refuses an API-key account whose Keychain secret changed, before any session row`), Task 6 (`asks the builder to confirm an account on its own directory, and Confirm records it`).
2. **A metered account crosses its monthly cap.**
   - Case: three lanes run when the cap is reached; the month rolls over at local midnight; the builder raises the cap; a lane hands off after the cap.
   - No new session starts, running ones finish, the card shows the overshoot as they end, the next month or a raised cap resumes the work, and a lane stops at its next session boundary.
   - Tests: Task 4 (`pauses at the cap until the next local month, with one card and account.cap_reached`, `rewrites the cap card with the overshoot as running sessions end`, `resumes when the cap is raised`, `launches nothing on a metered account at its monthly cap, and launches under it`, `stops a lane at its next session once its account reaches the monthly cap`).
3. **A secret leaks.**
   - Case: an API response, an event, a log line or a card carries the key; an agent runs `env`, `printenv`, `echo $ANTHROPIC_API_KEY`, `security find-generic-password`, `ps eww`, or reads `~/Library/Application Support/10db/accounts/…`, including through `sh -c` and `$(…)`, in a read-only step too; the gate prints `$ANTHROPIC_API_KEY`.
   - The secret appears nowhere outside the Keychain and the session's env; the guard denies each command with a reason; the gate never sees the key.
   - Tests: Task 8 (`takes a secret into the Keychain and never returns, emits or logs it`), Task 7 (`account isolation`: `denies %s in an implement step and a read-only step`, `denies %s under the data directory in both step kinds`), Task 5 (`gives the gate the project env, never the account's key`).
4. **A path with a space reaches a shell.**
   - Case: the default data directory is `~/Library/Application Support/10db`, so a config directory path has a space and can hold a quote.
   - The sign-in command quotes it as one shell word; the guard still recognises the path written with an escaped space or quotes.
   - Tests: Task 3 (`signInCommand`: `quotes %s as one shell word`), Task 7 (rows `the data directory, with escaped spaces`, `the data directory, partly quoted`, `the data directory through a repo link`), Task 8 (`creates a subscription with a private config directory and a sign-in command quoting its path`).
5. **Credentials expire mid-run.**
   - Case: a subscription's OAuth token can't refresh, or a Bedrock SSO session expires, while sessions run.
   - The session ends as an account refusal, the account pauses with the exact fix (`CLAUDE_CONFIG_DIR='…' claude /login` or `aws sso login --profile <p>`), and the work resumes the same conversation after Resume.
   - Tests: Task 5 (`ends a session that reports authentication_failed as signed out, before any tool runs`, `resumes the same conversation after credentials expired mid-session`), Task 6 (`starts one session at a time on a subscription account`).
6. **Two projects share one account.**
   - Case: projects A and B both bind a lane-cap-2 account with work queued in each; one project's session hits the usage limit.
   - At most two lanes run across both projects; the pause holds both projects' lanes on that account and no other account's.
   - Tests: Task 4 (`caps lanes per account across two projects`, `holds only the paused account's projects`, `re-queues only the paused account's work`).
7. **A fresh install starts work before Personal's identity is known.**
   - Case: the builder creates a project and starts a task on a new data directory, signed in or not.
   - The work waits `QUEUED` while the preparer probes the default directory, records the email it finds and launches; a signed-out default directory raises one card with `claude /login`, and 10db probes again at most once a minute.
   - Tests: Task 6 (`records Personal's identity from its first probe of the default directory, then asks for a tick`, `raises one sign-in card when the default directory is signed out, and probes again only after a minute`, and `start.test.ts`'s `records Personal's identity from its first probe, then runs the task`).

```ts
  AccountKind.Bedrock,
  AccountKind.Gateway,

  AccountKind.AnthropicApiKey,
  AccountKind.Bedrock,
  AccountKind.Gateway,

  WrongCredentials: 'wrong_credentials',
  SignedOut: 'signed_out',
  SecretMissing: 'secret_missing',
  SecretChanged: 'secret_changed',

  aliases: z.array(Alias).min(1).optional(),

export type BedrockSettings = z.infer<typeof BedrockSettings>;
```

```ts
  AccountId,
  AccountInput,
  AccountKind,
  AccountPatch,

  DEFAULT_ACCOUNT_LABEL,
  DEFAULT_ACCOUNT_LANE_CAP,
  EventType,
  InvalidError,

  type AccountDto,
  type AccountSettings,
} from '@10db/contracts';
import { and, asc, eq, ne } from 'drizzle-orm';
import { z } from 'zod';
import * as schema from '../schema';
import { getAppSetting, setAppSetting } from './settings';
import type { DbReader, WriteContext } from './store';

export type AccountRow = typeof schema.accounts.$inferSelect;

/** The app setting naming the account new projects bind to when they name none. */
const DEFAULT_ACCOUNT_KEY = 'accounts.default';
const Email = z.email();

/** The Keychain account (service `10db`) that holds an account's secret. */
export function accountSecretRef(id: AccountId): string {
  return `account:${id}`;
}

export function defaultAccountId(db: DbReader): AccountId | null {
  const parsed = AccountId.safeParse(getAppSetting(db, DEFAULT_ACCOUNT_KEY));
  return parsed.success ? parsed.data : null;
}

function toDto(db: DbReader, row: AccountRow): AccountDto {
  return {
    id: row.id,
    kind: row.kind,
    label: row.label,
    payer: row.payer,
    expectedIdentity: row.expectedIdentity,
    configDir: row.configDir,
    // Stored JSON is parsed for its kind on the way out, so a drifted row fails loudly here.
    settings: parseAccountSettings(row.kind, row.settings),
    laneCap: row.laneCap,
    monthlyCapUsd: row.monthlyCapUsd,
    archived: row.archived,
    isDefault: defaultAccountId(db) === row.id,
    secretSet: row.secretFingerprint !== null,
    createdAt: row.createdAt,
    updatedAt: row.updatedAt,
  };
}

/** `fields` names what changed; a value never goes into the event log. */
function saved(ctx: WriteContext, id: AccountId, fields: readonly string[]): void {
  ctx.emit({
    type: EventType.AccountSaved,
    entityType: 'account',
    entityId: id,
    data: { fields: [...fields] },
  });
}

function refuseTakenLabel(db: DbReader, label: string, except: AccountId | null): void {
  const taken = db
    .select({ id: schema.accounts.id })
    .from(schema.accounts)
    .where(
      except
        ? and(eq(schema.accounts.label, label), ne(schema.accounts.id, except))
        : eq(schema.accounts.label, label),
    )
    .get();
  if (taken) throw new ConflictError(`An account is already called "${label}"`);
}

export function getAccountRow(db: DbReader, id: AccountId): AccountRow {
  const row = db.select().from(schema.accounts).where(eq(schema.accounts.id, id)).get();
  if (!row) throw new NotFoundError('account', id);
  return row;
}

export function getAccount(db: DbReader, id: AccountId): AccountDto {
  return toDto(db, getAccountRow(db, id));
}

export function listAccounts(
  db: DbReader,
  opts: { readonly includeArchived?: boolean } = {},
): AccountDto[] {
  const rows = db.select().from(schema.accounts).orderBy(asc(schema.accounts.label)).all();
  return rows.filter((r) => opts.includeArchived === true || !r.archived).map((r) => toDto(db, r));
}

export function insertAccount(
  ctx: WriteContext,
  input: AccountInput,
  opts: { configDirFor(id: AccountId): string },
): AccountDto {
  const config = AccountInput.parse(input);
  refuseTakenLabel(ctx.tx, config.label, null);
  const id = mintId('Account');
  const row: AccountRow = {
    id,
    kind: config.kind,
    label: config.label,
    payer: config.payer,
    expectedIdentity: 'expectedIdentity' in config ? config.expectedIdentity : null,
    configDir: config.kind === AccountKind.ClaudeSubscription ? opts.configDirFor(id) : null,
    secretRef: needsSecret(config.kind, config.settings) ? accountSecretRef(id) : null,
    secretFingerprint: null,
    settings: config.settings,
    laneCap: config.laneCap,
    monthlyCapUsd: 'monthlyCapUsd' in config ? config.monthlyCapUsd : null,
    archived: false,
    createdAt: ctx.now,
    updatedAt: ctx.now,
  };
  ctx.tx.insert(schema.accounts).values(row).run();
  saved(ctx, id, ['created']);
  return toDto(ctx.tx, row);
}

/** Settings checked against the account's own kind; a mismatch is the caller's mistake (400). */
function settingsFor(row: AccountRow, raw: unknown): AccountSettings {
  try {
    return parseAccountSettings(row.kind, raw);
  } catch (error) {
    if (error instanceof z.ZodError)
      throw new InvalidError(
        `Those settings don't fit a ${row.kind} account: ${error.issues.map((i) => i.message).join('; ')}`,
      );
    throw error;
  }
}

export function patchAccount(ctx: WriteContext, id: AccountId, patch: AccountPatch): AccountDto {
  const changes = AccountPatch.parse(patch);
  const row = getAccountRow(ctx.tx, id);
  if (row.archived) throw new ConflictError(`Account "${row.label}" is archived`);
  if (changes.label !== undefined) refuseTakenLabel(ctx.tx, changes.label, id);
  if (typeof changes.monthlyCapUsd === 'number' && !isMetered(row.kind))
    throw new InvalidError('Only API-key, Bedrock and gateway accounts take a monthly dollar cap');
  if (typeof changes.expectedIdentity === 'string') {
    if (row.kind === AccountKind.Gateway)
      throw new InvalidError(
        'A gateway account is identified by its key, not an expected identity',
      );
    if (
      row.kind === AccountKind.ClaudeSubscription &&
      !Email.safeParse(changes.expectedIdentity).success
    )
      throw new InvalidError("A subscription's expected identity is the email it signs in as");
  }
  const settings = changes.settings === undefined ? undefined : settingsFor(row, changes.settings);
  // A Bedrock account moving between a profile and a bearer token gains or loses its secret.
  const secretRef =
    settings === undefined
      ? row.secretRef
      : needsSecret(row.kind, settings)
        ? accountSecretRef(id)
        : null;
  ctx.tx
    .update(schema.accounts)
    .set({
      ...(changes.label !== undefined ? { label: changes.label } : {}),
      ...(changes.payer !== undefined ? { payer: changes.payer } : {}),
      ...(changes.laneCap !== undefined ? { laneCap: changes.laneCap } : {}),
      ...(changes.monthlyCapUsd !== undefined ? { monthlyCapUsd: changes.monthlyCapUsd } : {}),
      ...(changes.expectedIdentity !== undefined
        ? { expectedIdentity: changes.expectedIdentity }
        : {}),
      ...(settings !== undefined
        ? {
            settings,
            secretRef,
            secretFingerprint: secretRef === null ? null : row.secretFingerprint,
          }
        : {}),
      updatedAt: ctx.now,
    })
    .where(eq(schema.accounts.id, id))
    .run();
  saved(ctx, id, Object.keys(changes).sort());
  return getAccount(ctx.tx, id);
}

/** Archiving is refused while a project binds the account, and for the default account. */
export function archiveAccount(ctx: WriteContext, id: AccountId): AccountDto {
  const row = getAccountRow(ctx.tx, id);
  if (row.archived) return getAccount(ctx.tx, id);
  if (defaultAccountId(ctx.tx) === id)
    throw new ConflictError(
      `"${row.label}" is the default account for new projects, so it can't be archived`,
    );
  const bound = ctx.tx
    .select({ name: schema.projects.name })
    .from(schema.projects)
    .where(eq(schema.projects.accountId, id))
    .all();
  if (bound.length > 0)
    throw new ConflictError(
      `Move ${bound.map((p) => `"${p.name}"`).join(', ')} to another account before archiving "${row.label}"`,
    );
  ctx.tx
    .update(schema.accounts)
    .set({ archived: true, updatedAt: ctx.now })
    .where(eq(schema.accounts.id, id))
    .run();
  saved(ctx, id, ['archived']);
  return getAccount(ctx.tx, id);
}

/** Records the fingerprint of the secret just stored in the Keychain; the secret itself is never passed here. */
export function recordAccountSecret(
  ctx: WriteContext,
  id: AccountId,
  fingerprint: string,
): AccountDto {
  const row = getAccountRow(ctx.tx, id);
  if (row.archived) throw new ConflictError(`Account "${row.label}" is archived`);
  if (row.secretRef === null) throw new InvalidError(`Account "${row.label}" takes no secret`);
  ctx.tx
    .update(schema.accounts)
    .set({ secretFingerprint: fingerprint, updatedAt: ctx.now })
    .where(eq(schema.accounts.id, id))
    .run();
  saved(ctx, id, ['secret']);
  return getAccount(ctx.tx, id);
}

/**

 * directory, and the default for new projects (accounts spec §3 "accounts start fresh").
 */

  opts: { readonly expectedIdentity: string | null },
): AccountDto | null {

  const row: AccountRow = {
    id: mintId('Account'),
    kind: AccountKind.ClaudeSubscription,
    label: DEFAULT_ACCOUNT_LABEL,
    payer: '',
    expectedIdentity: opts.expectedIdentity,
    configDir: null,
    secretRef: null,
    secretFingerprint: null,
    settings: {},
    laneCap: DEFAULT_ACCOUNT_LANE_CAP,
    monthlyCapUsd: null,
    archived: false,
    createdAt: ctx.now,
    updatedAt: ctx.now,
  };
  ctx.tx.insert(schema.accounts).values(row).run();
  setAppSetting(ctx, DEFAULT_ACCOUNT_KEY, row.id);
  saved(ctx, row.id, ['created']);
  return toDto(ctx.tx, row);
}
```

```ts
import { isMetered, type AccountId, type AccountUsageDto, type UsageTotals } from '@10db/contracts';
import { and, asc, eq, gte, lt, sql } from 'drizzle-orm';
import * as schema from '../schema';
import { getAccountRow } from './accounts';
import type { DbReader } from './store';

/** A calendar month as ISO instants: `start` inclusive, `end` exclusive. The daemon computes it in local time. */
export interface UsageWindow {
  readonly month: string;
  readonly start: string;
  readonly end: string;
}

/** Sessions on the account that started in the window (accounts spec §6: usage is a query, not a ledger). */
function inWindow(id: AccountId, window: UsageWindow) {
  return and(
    eq(schema.sessions.accountId, id),
    gte(schema.sessions.startedAt, window.start),
    lt(schema.sessions.startedAt, window.end),
  );
}

export function accountSpendUsd(db: DbReader, id: AccountId, window: UsageWindow): number {
  const row = db
    .select({ total: sql<number | null>`sum(${schema.sessions.costUsd})` })
    .from(schema.sessions)
    .where(inWindow(id, window))
    .get();
  return row?.total ?? 0;
}

export function accountUsage(db: DbReader, id: AccountId, window: UsageWindow): AccountUsageDto {
  const account = getAccountRow(db, id);
  const metered = isMetered(account.kind);
  const rows = db
    .select({
      projectId: schema.projects.id,
      projectName: schema.projects.name,
      tokensIn: sql<number>`coalesce(sum(${schema.sessions.inputTokens}), 0)`,
      tokensOut: sql<number>`coalesce(sum(${schema.sessions.outputTokens}), 0)`,
      tokensCached: sql<number>`coalesce(sum(${schema.sessions.cachedTokens}), 0)`,
      costUsd: sql<number | null>`sum(${schema.sessions.costUsd})`,
    })
    .from(schema.sessions)
    .innerJoin(schema.workstreams, eq(schema.workstreams.id, schema.sessions.workstreamId))
    .innerJoin(schema.projects, eq(schema.projects.id, schema.workstreams.projectId))
    .where(inWindow(id, window))
    .groupBy(schema.projects.id)
    .orderBy(asc(schema.projects.name))
    .all();
  const byProject = rows.map((r) => ({ ...r, costUsd: metered ? (r.costUsd ?? 0) : null }));
  const zero: UsageTotals = {
    tokensIn: 0,
    tokensOut: 0,
    tokensCached: 0,
    costUsd: metered ? 0 : null,
  };
  const total = byProject.reduce<UsageTotals>(
    (sum, r) => ({
      tokensIn: sum.tokensIn + r.tokensIn,
      tokensOut: sum.tokensOut + r.tokensOut,
      tokensCached: sum.tokensCached + r.tokensCached,
      costUsd: sum.costUsd === null || r.costUsd === null ? null : sum.costUsd + r.costUsd,
    }),
    zero,
  );
  return {
    accountId: id,
    month: window.month,
    total,
    monthlyCapUsd: account.monthlyCapUsd,
    byProject,
  };
}
```

```ts
import type { ExecFileSyncOptionsWithStringEncoding } from 'node:child_process';
import { describe, expect, it } from 'vitest';
import { KeychainError, keychainWith, secretFingerprint, unavailableKeychain } from './index';

type Call = { args: readonly string[]; input: unknown };

/** A Keychain double at the `security` boundary: `-i` writes go to `items`, reads come from it. */
function securityDouble(opts: { mangle?: (s: string) => string } = {}) {
  const items = new Map<string, string>();
  const calls: Call[] = [];
  const exec = (
    _cmd: string,
    args: readonly string[],
    options: ExecFileSyncOptionsWithStringEncoding,
  ): string => {
    calls.push({ args, input: options.input });
    if (args[0] === '-i') {
      const line = String(options.input);
      const match = /-a "([^"]+)" -w "([^"]*)"/.exec(line);
      if (match?.[1] !== undefined && match[2] !== undefined)
        items.set(match[1], opts.mangle ? opts.mangle(match[2]) : match[2]);
      return '';
    }
    const account = args[args.indexOf('-a') + 1] ?? '';
    const value = items.get(account);
    if (value === undefined) throw Object.assign(new Error('not found'), { status: 44 });
    return `${value}\n`;
  };
  return { exec, items, calls };
}

describe('keychainWith', () => {
  it('writes through security -i on standard input, never on the command line, and reads it back', () => {
    const security = securityDouble();
    const keychain = keychainWith(security.exec);
    keychain.write('account:acc_1', 'sk-ant-SECRET-1234');
    expect(keychain.read('account:acc_1')).toBe('sk-ant-SECRET-1234');
    const write = security.calls[0];
    expect(write?.args).toEqual(['-i']);
    expect(String(write?.input)).toContain(
      'add-generic-password -U -s 10db -a "account:acc_1" -w "sk-ant-SECRET-1234"',
    );
    for (const call of security.calls) expect(call.args.join(' ')).not.toContain('SECRET');
  });

  it('refuses a secret security -i would split or unquote, before running anything', () => {
    const security = securityDouble();
    const keychain = keychainWith(security.exec);
    for (const bad of ['has space', 'quote"d', 'back\\slash', 'new\nline'])
      expect(() => {
        keychain.write('account:acc_1', bad);
      }).toThrow(KeychainError);
    expect(security.calls).toEqual([]);
  });

  it('fails a write the Keychain did not store as given, naming no value', () => {
    const keychain = keychainWith(securityDouble({ mangle: (s) => s.slice(1) }).exec);
```

```ts
import { createHash } from 'node:crypto';
import { execFileSync, type ExecFileSyncOptionsWithStringEncoding } from 'node:child_process';

export const KEYCHAIN_SERVICE = '10db';
/** The Keychain account of the builder's Artificial Analysis key. */
export const AA_KEY_ACCOUNT = 'artificial-analysis-api-key';
const KEYCHAIN_TIMEOUT_MS = 5_000;
/** `security` exits with this status when the Keychain has no such item. */
const ITEM_NOT_FOUND = 44;
/** The secret reaches `security -i` inside double quotes, so it can hold no whitespace, quote or backslash. */
const SAFE_SECRET = /^[\x21\x23-\x5b\x5d-\x7e]+$/;
const SAFE_ACCOUNT = /^[A-Za-z0-9:_.-]+$/;
const FINGERPRINT_HEX = 16;

export type KeychainExec = (
  command: string,
  args: readonly string[],
  options: ExecFileSyncOptionsWithStringEncoding,
) => string;

/** The Keychain could not be read or written. The message names the item and the status, never a value. */
export class KeychainError extends Error {
  override readonly name = 'KeychainError';
}

/** Items in the login Keychain under service `10db`. Secrets are read when needed and never cached. */
export interface Keychain {
  /** The secret, or null when the item is missing or empty. */
  read(account: string): string | null;
  /** Adds or replaces the item, then reads it back. */
  write(account: string, secret: string): void;
}

function failure(error: unknown): string {
  // Execution errors carry the command line and its output, which can hold a value; only the codes are used.
  const e = error as { status?: number | null; code?: string; signal?: string | null };
  if (e.code === 'ETIMEDOUT') return `timed out after ${String(KEYCHAIN_TIMEOUT_MS / 1000)} s`;
  if (typeof e.status === 'number') return `security exit status ${String(e.status)}`;
  return e.code ?? e.signal ?? 'unknown error';
}

/**
 * A Keychain over `exec`. Only "item not found" means there is no secret; a timeout, a locked or
 * unreachable Keychain or a denied prompt throws, because telling the builder to add a secret that
 * exists would send them the wrong way.
 */
export function keychainWith(exec: KeychainExec): Keychain {
  const read = (account: string): string | null => {
    try {
      const value = exec(
        '/usr/bin/security',
        ['find-generic-password', '-s', KEYCHAIN_SERVICE, '-a', account, '-w'],
        { encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'], timeout: KEYCHAIN_TIMEOUT_MS },
      ).trim();
      return value.length > 0 ? value : null;
    } catch (error) {
      // A thrown exec error has a numeric `status` when security ran and exited non-zero.
      if ((error as { status?: unknown }).status === ITEM_NOT_FOUND) return null;
      throw new KeychainError(`Reading the Keychain item ${account} failed (${failure(error)})`);
    }
  };
  return {
    read,
    write(account, secret) {
      if (!SAFE_ACCOUNT.test(account))
        throw new KeychainError(`${account} is not a Keychain account name 10db writes`);
      if (!SAFE_SECRET.test(secret))
        throw new KeychainError(
          'The secret must be printable ASCII with no spaces, double quotes or backslashes',
        );
      try {
        // Interactive mode reads the command from standard input, so the secret is never on a command line.
        exec('/usr/bin/security', ['-i'], {
          encoding: 'utf8',
          input: `add-generic-password -U -s ${KEYCHAIN_SERVICE} -a "${account}" -w "${secret}"\n`,
          stdio: ['pipe', 'ignore', 'ignore'],
          timeout: KEYCHAIN_TIMEOUT_MS,
        });
      } catch (error) {
        throw new KeychainError(`Writing the Keychain item ${account} failed (${failure(error)})`);
      }
      // `security -i` can report a failed command without a failing exit status.
      if (read(account) !== secret)
        throw new KeychainError(`The Keychain did not store the secret for ${account} as given`);
    },
  };
}

export const systemKeychain: Keychain = keychainWith(execFileSync);

/** For a daemon started without a Keychain (tests): nothing to read, and writing is refused. */
export const unavailableKeychain: Keychain = {
  read: () => null,
  write: (account) => {
    throw new KeychainError(
      `No Keychain is available to this daemon, so ${account} was not written`,
    );
  },
};

/** Enough to tell two secrets apart, never enough to recover one. */
export function secretFingerprint(secret: string): string {
  return `sha256:${createHash('sha256').update(secret).digest('hex').slice(0, FINGERPRINT_HEX)}`;
}
```

```ts
/** The account can't start a session as it stands; the message names the account, never a value. */
export class AccountLaunchError extends Error {
  override readonly name = 'AccountLaunchError';
  readonly accountId: AccountId;
  readonly problem: AccountProblem;
  constructor(accountId: AccountId, problem: AccountProblem, message: string) {
    super(message);
    this.accountId = accountId;
    this.problem = problem;
  }

/** The one owner of account variables (accounts spec §3). */
export interface Launcher {
  /** The login env with every billing switch stripped: for the gate and the repo's MCP servers. */
  projectEnv(): Record<string, string>;
  /** A session on `account` asking for `alias`; reads a keyed account's secret now and caches nothing. */
  session(account: AccountRow, alias: string): SessionLaunch;
  /** The same environment, for reading who the account is without a prompt. */
  probe(account: AccountRow): ProbeLaunch;
}

function quoted(text: string): string {
  return `'${text.replaceAll("'", `'\\''`)}'`;
}

/** Signs a subscription in with the unmodified `claude`; the path is one shell word even with spaces. */
export function signInCommand(configDir: string | null): string {
  return configDir === null
    ? 'claude /login'
    : `CLAUDE_CONFIG_DIR=${quoted(configDir)} claude /login`;
}

export function createLauncher(opts: {
  readonly base: Readonly<Record<string, string>>;
  readonly clientApp: string;
  readonly keychain: Keychain;
}): Launcher {
  const projectEnv = (): Record<string, string> => stripBillingSwitches(opts.base);

  function secretOf(account: AccountRow): string {
    const missing = new AccountLaunchError(
      account.id,
      AccountProblem.SecretMissing,
      `Account "${account.label}" has no secret set through 10db`,
    );
    if (account.secretRef === null || account.secretFingerprint === null) throw missing;
    const secret = opts.keychain.read(account.secretRef);
    if (secret === null) throw missing;
    if (secretFingerprint(secret) !== account.secretFingerprint)
      throw new AccountLaunchError(
        account.id,
        AccountProblem.SecretChanged,
        `The Keychain secret of account "${account.label}" changed outside 10db`,
      );
    return secret;
  }

  function build(account: AccountRow): {
    env: Record<string, string>;
    modelMap: Readonly<Record<string, string>>;
  } {
    const env: Record<string, string> = { ...projectEnv(), [CLIENT_APP_VAR]: opts.clientApp };
    switch (account.kind) {
      case AccountKind.ClaudeSubscription: {
        const settings = SubscriptionSettings.parse(account.settings);
        if (account.configDir !== null) env['CLAUDE_CONFIG_DIR'] = account.configDir;
        return { env, modelMap: settings.modelMap ?? {} };
      }
      case AccountKind.AnthropicApiKey: {
        const settings = ApiKeySettings.parse(account.settings);
        env['ANTHROPIC_API_KEY'] = secretOf(account);
        return { env, modelMap: settings.modelMap ?? {} };
      }
      case AccountKind.Bedrock: {
        const settings = BedrockSettings.parse(account.settings);
        for (const name of AWS_LOGIN_VARS) delete env[name];
        env['CLAUDE_CODE_USE_BEDROCK'] = '1';
        env['AWS_REGION'] = settings.region;
        if (settings.awsProfile === null) env['AWS_BEARER_TOKEN_BEDROCK'] = secretOf(account);
        else env['AWS_PROFILE'] = settings.awsProfile;
        return { env, modelMap: settings.modelMap ?? {} };
      }
      case AccountKind.Gateway: {
        const settings = GatewaySettings.parse(account.settings);
        env['ANTHROPIC_BASE_URL'] = settings.baseUrl;
        env['ANTHROPIC_AUTH_TOKEN'] = secretOf(account);
        return { env, modelMap: settings.modelMap ?? {} };
      }
    }
  }

  const expectation = (account: AccountRow): AccountExpectation => ({
    accountId: account.id,
    label: account.label,
    kind: account.kind,
    identity: account.expectedIdentity,
  });

  return {
    projectEnv,
    session(account, alias) {
      const { env, modelMap } = build(account);
      return { env, model: modelMap[alias] ?? alias, expect: expectation(account) };
    },
    probe(account) {
      return { env: build(account).env, expect: expectation(account) };
    },
  };
}
```

```ts
import { Month } from '@10db/contracts';
import type { UsageWindow } from '@10db/db';

export interface MonthWindow {
  readonly month: string;
  readonly start: Date;
  readonly end: Date;
}

const pad = (n: number): string => String(n).padStart(2, '0');

/** The calendar month containing `at`, in the machine's local time (accounts spec §6). */
export function monthOf(at: Date): MonthWindow {
  const start = new Date(at.getFullYear(), at.getMonth(), 1);
  const end = new Date(at.getFullYear(), at.getMonth() + 1, 1);
  return { month: `${String(start.getFullYear())}-${pad(start.getMonth() + 1)}`, start, end };
}

/** A `YYYY-MM` month, in local time. */
export function monthWindow(month: string): MonthWindow {
  const valid = Month.parse(month);
  return monthOf(new Date(Number(valid.slice(0, 4)), Number(valid.slice(5, 7)) - 1, 1));
}

export function usageWindow(window: MonthWindow): UsageWindow {
  return { month: window.month, start: window.start.toISOString(), end: window.end.toISOString() };
}
```

```ts
import { monthOf, usageWindow, type MonthWindow } from './month';

export interface CapStatus {
  readonly spentUsd: number;
  readonly capUsd: number;
  readonly window: MonthWindow;
}

/** A metered account's spend this month against its cap; null when it has no cap (accounts spec §6). */
export function capStatus(db: DbReader, account: AccountRow, now: Date): CapStatus | null {
  if (account.monthlyCapUsd === null || !isMetered(account.kind)) return null;
  const window = monthOf(now);
  return {

    capUsd: account.monthlyCapUsd,
    window,
  };
```

```ts
  deleteAppSetting,

import { z } from 'zod';
import type { Clock, Timer } from '../clock';
import type { StateStore } from '../events';
import type { InboxService } from '../inbox';
import type { AccountCard } from './cards';

export interface AccountPause {
  readonly reason: AccountPauseReason;
  /** When it ends; null until the account is saved or its card answered. */
  readonly until: Date | null;
}

export interface AccountPauses {
  /** Pauses the account unless a pause that outlasts this one holds it; the card is raised either way (it folds). */
  pause(
    accountId: AccountId,
    pause: AccountPause,
    at: {
      readonly projectId: ProjectId;
      readonly card: AccountCard;
      readonly data?: Record<string, Json>;
    },
  ): void;
  pausedFor(accountId: AccountId): AccountPause | null;
  resume(accountId: AccountId): void;
  /** Re-arms pauses persisted before a restart. */
  restore(): void;
  stop(): void;
}

const PauseSetting = z.object({
  reason: z.enum(AccountPauseReason),
  until: z.iso.datetime().nullable(),
});
const settingKey = (id: AccountId): string => `account_pause.${id}`;

/** A pause with no end outranks one that ends; otherwise the later end wins. */
function outlasts(next: AccountPause, current: AccountPause): boolean {
  if (next.until === null) return current.until !== null;
  if (current.until === null) return false;
  return next.until > current.until;
}

/** One pause per account (accounts spec §3: a usage-limit pause applies to the account that hit it). */
export function createAccountPauses(opts: {
  readonly state: StateStore;
  readonly clock: Clock;
  readonly inbox: InboxService;
  stopAccount(accountId: AccountId): Promise<void>;
  onResume(): void;
}): AccountPauses {
  const paused = new Map<AccountId, AccountPause>();
  const timers = new Map<AccountId, Timer>();

  function arm(id: AccountId, pause: AccountPause): void {
    timers.get(id)?.cancel();
    timers.delete(id);
    paused.set(id, pause);
    if (pause.until === null) return;
    timers.set(
      id,
      opts.clock.setTimeout(
        () => {
          resume(id);
        },
        Math.max(0, pause.until.getTime() - opts.clock.now().getTime()),
      ),
    );
  }

  function resume(id: AccountId): void {
    timers.get(id)?.cancel();
    timers.delete(id);
    const was = paused.get(id);
    paused.delete(id);
    opts.state.write((ctx) => {
      deleteAppSetting(ctx, settingKey(id));
      for (const ws of listWorkstreams(ctx.tx, { states: [WorkstreamState.PausedLimit] })) {
        if (getProject(ctx.tx, ws.projectId).accountId !== id) continue;
        transitionWorkstream(ctx, ws.id, {
          to: WorkstreamState.Queued,
          fence: null,
          patch: { pausedUntil: null },
          reason: 'the account resumed',
        });
      }
      ctx.emit({
        type: EventType.AccountResumed,
        entityType: 'account',
        entityId: id,
        data: { reason: was?.reason ?? null },
      });
    });
    opts.onResume();
  }

  return {
    pause(id, pause, at) {
      const current = paused.get(id);
      if (!current || outlasts(pause, current)) {
        arm(id, pause);
        opts.state.write((ctx) => {
          const until = pause.until?.toISOString() ?? null;
          setAppSetting(ctx, settingKey(id), { reason: pause.reason, until });
          const data = { reason: pause.reason, until, ...at.data };
          ctx.emit({ type: EventType.AccountPaused, entityType: 'account', entityId: id, data });
          if (pause.reason === AccountPauseReason.MonthlyCap)
            ctx.emit({
              type: EventType.AccountCapReached,
              entityType: 'account',
              entityId: id,
              data,
            });
        });
      }
      opts.inbox.flag({
        projectId: at.projectId,
        workstreamId: null,
        title: at.card.title,
        body: at.card.body,
        detail: at.card.detail,
        foldKey: at.card.foldKey,
        ...(at.card.options ? { options: at.card.options } : {}),
      });
      // Only a usage limit stops running sessions; a capped or refused account lets them finish.
      if (pause.reason === AccountPauseReason.UsageLimit) void opts.stopAccount(id);
    },
    pausedFor: (id) => paused.get(id) ?? null,
    resume(id) {
      if (paused.has(id)) resume(id);
    },
    restore() {
      for (const account of listAccounts(opts.state.db, { includeArchived: true })) {
        const parsed = PauseSetting.safeParse(getAppSetting(opts.state.db, settingKey(account.id)));
        if (!parsed.success) continue;
        const until = parsed.data.until === null ? null : new Date(parsed.data.until);
        if (until !== null && until <= opts.clock.now()) resume(account.id);
        else arm(account.id, { reason: parsed.data.reason, until });
      }
    },
    stop() {
      for (const timer of timers.values()) timer.cancel();
      timers.clear();
    },
  };
}
```

```ts
import {

  type AccountId,
  type AccountRefusal,
  type ProjectId,
} from '@10db/contracts';
import { findOpenByFoldKey, getAccountRow, type AccountRow } from '@10db/db';
import type { Clock } from '../clock';
import type { StateStore } from '../events';
import type { InboxService } from '../inbox';
import { capStatus } from './cap';
import { accountFoldKey, capCard, refusedCard, usageLimitCard } from './cards';
import type { AccountPause, AccountPauses } from './pauses';

/** What the scheduler and the runner ask about an account before and after a session. */
export interface AccountRuntime {
  /** Why no session may start on it now: a pause, or its monthly cap (which this call pauses it for). */
  blocked(account: AccountRow, projectId: ProjectId): AccountPause | null;
  /** A usage limit: pauses it until the reset (or the default length) and stops its running lanes. */
  rateLimited(accountId: AccountId, resetsAt: Date | null, projectId: ProjectId): void;
  /** A session on it was refused for its identity or credentials: pauses it until it is saved. */
  refused(account: AccountRow, projectId: ProjectId, refusal: AccountRefusal): void;
  /** A session on it ended: an open cap card shows the spend so far. */
  sessionEnded(account: AccountRow, projectId: ProjectId): void;
  isPaused(accountId: AccountId): boolean;
  /** It was saved: a cap or refusal pause ends, and the next check decides again. */
  saved(accountId: AccountId): void;
}

export function createAccountRuntime(opts: {
  readonly state: StateStore;
  readonly clock: Clock;
  readonly inbox: InboxService;
  readonly pauses: AccountPauses;
  readonly defaultPauseMs: number;
}): AccountRuntime {
  const db = opts.state.db;
  return {
    blocked(account, projectId) {
      const paused = opts.pauses.pausedFor(account.id);
      if (paused) return paused;
      const cap = capStatus(db, account, opts.clock.now());
      if (!cap || cap.spentUsd < cap.capUsd) return null;
      const pause: AccountPause = { reason: AccountPauseReason.MonthlyCap, until: cap.window.end };
      opts.pauses.pause(account.id, pause, {
        projectId,
        card: capCard(account, cap),
        data: { month: cap.window.month, spentUsd: cap.spentUsd, capUsd: cap.capUsd },
      });
      return pause;
    },
    rateLimited(accountId, resetsAt, projectId) {
      const now = opts.clock.now();
      const until =
        resetsAt && resetsAt > now ? resetsAt : new Date(now.getTime() + opts.defaultPauseMs);
      opts.pauses.pause(
        accountId,
        { reason: AccountPauseReason.UsageLimit, until },
        { projectId, card: usageLimitCard(getAccountRow(db, accountId), until) },
      );
    },
    refused(account, projectId, refusal) {
      opts.pauses.pause(
        account.id,
        { reason: AccountPauseReason.Refused, until: null },
        { projectId, card: refusedCard(account, refusal), data: { problem: refusal.problem } },
      );
    },
    sessionEnded(account, projectId) {
      if (opts.pauses.pausedFor(account.id)?.reason !== AccountPauseReason.MonthlyCap) return;
      const cap = capStatus(db, account, opts.clock.now());
      const open = findOpenByFoldKey(
        db,
        projectId,
        accountFoldKey(account.id, AccountPauseReason.MonthlyCap),
      );
      if (cap && open) opts.inbox.reword(open.id, capCard(account, cap).body);
    },
    isPaused: (accountId) => opts.pauses.pausedFor(accountId) !== null,
    saved(accountId) {
      const paused = opts.pauses.pausedFor(accountId);
      if (paused && paused.reason !== AccountPauseReason.UsageLimit) opts.pauses.resume(accountId);
    },
  };
}
```

### Task 5: Sessions verify their account before the prompt

Sessions launch through the launcher and prove their account (accounts spec §5).

- **Before the prompt:** `accountInfo()` must show the account's identity and the credential its kind needs.

```ts
/** What Claude Code reports about the account a session runs on (`accountInfo()`). */
export interface SeenAccount {
  readonly email: string | undefined;
  readonly organization: string | undefined;
  readonly subscriptionType: string | undefined;
  readonly tokenSource: string | undefined;
  readonly apiKeySource: string | undefined;
  readonly apiProvider: string | undefined;
}

export function seenFrom(info: {
  readonly email?: string;
  readonly organization?: string;
  readonly subscriptionType?: string;
  readonly tokenSource?: string;
  readonly apiKeySource?: string;
  readonly apiProvider?: string;
}): SeenAccount {
  return {
    email: info.email,
    organization: info.organization,
    subscriptionType: info.subscriptionType,
    tokenSource: info.tokenSource,
    apiKeySource: info.apiKeySource,
    apiProvider: info.apiProvider,
  };
}

const NEEDS: Readonly<Record<SupportedAccountKind, string>> = {
  [AccountKind.ClaudeSubscription]: 'a Claude subscription',
  [AccountKind.AnthropicApiKey]: 'an Anthropic API key',
  [AccountKind.Bedrock]: 'Bedrock',
  [AccountKind.Gateway]: 'a gateway token',
};

const noKey = (source: string | undefined): boolean => source === undefined || source === 'none';

/** Key sources and providers only: never an email or organization, so it can be logged. */
function described(seen: SeenAccount): string {
  return `apiKeySource ${seen.apiKeySource ?? 'unreported'}, apiProvider ${seen.apiProvider ?? 'unreported'}, tokenSource ${seen.tokenSource ?? 'unreported'}, subscription ${seen.subscriptionType ? 'yes' : 'no'}`;
}

/**
 * Whether Claude Code bills the credential the kind needs. Only values a real session has shown are
 * accepted (spike 12 for the gateway), so a renamed variable fails loudly instead of billing someone else.
 */
function credentialsMatch(kind: SupportedAccountKind, seen: SeenAccount): boolean {
  switch (kind) {
    case AccountKind.ClaudeSubscription:
      // A plan's name is never compared; a gateway also looks first-party, so its token source rules it out.
      return (
        noKey(seen.apiKeySource) &&
        seen.apiProvider === 'firstParty' &&
        Boolean(seen.subscriptionType) &&
        seen.tokenSource !== 'ANTHROPIC_AUTH_TOKEN'
      );
    case AccountKind.AnthropicApiKey:
      return seen.apiKeySource === 'ANTHROPIC_API_KEY' && seen.apiProvider === 'firstParty';
    case AccountKind.Bedrock:
      return seen.apiProvider === 'bedrock';
    case AccountKind.Gateway:
      return (
        seen.tokenSource === 'ANTHROPIC_AUTH_TOKEN' &&
        seen.apiProvider === 'firstParty' &&
        noKey(seen.apiKeySource)
      );
  }
}

const same = (a: string, b: string): boolean => a.trim().toLowerCase() === b.trim().toLowerCase();

/** Before the prompt (accounts spec §5): who Claude Code is, and the credential it bills. */
export function checkAccount(expect: AccountExpectation, seen: SeenAccount): AccountRefusal | null {
  const who = `account "${expect.label}"`;
  if (
    expect.kind === AccountKind.ClaudeSubscription &&
    !seen.email &&
    !seen.subscriptionType &&
    noKey(seen.apiKeySource)
  )
    return {
      problem: AccountProblem.SignedOut,
      message: `Claude Code is not signed in for ${who}`,
      seenIdentity: null,
    };
  if (!credentialsMatch(expect.kind, seen))
    return {
      problem: AccountProblem.WrongCredentials,
      message: `${who} needs ${NEEDS[expect.kind]} but Claude Code reported ${described(seen)}`,
      seenIdentity: null,
    };
  if (expect.identity === null) return null;
  const subscription = expect.kind === AccountKind.ClaudeSubscription;
  const reported = subscription ? seen.email : seen.organization;
  if (reported !== undefined && same(reported, expect.identity)) return null;
  return {
    problem: AccountProblem.IdentityMismatch,
    message: `Claude Code reported a different ${subscription ? 'email' : 'organization'} than the one confirmed for ${who}`,
    seenIdentity: reported ?? null,
  };
}

/** At the first init: the key source the CLI actually used, with the provider and plan the preflight saw. */
export function checkInitCredentials(
  expect: AccountExpectation,
  apiKeySource: string | undefined,
  preflight: SeenAccount,
): AccountRefusal | null {
  const seen = { ...preflight, apiKeySource };
  return credentialsMatch(expect.kind, seen)
    ? null
    : {
        problem: AccountProblem.WrongCredentials,
        message: `account "${expect.label}" needs ${NEEDS[expect.kind]} but Claude Code started with ${described(seen)}`,
        seenIdentity: null,
      };
}

const ALIAS = /^[a-z]+$/;

/** An alias matches the model ID Claude Code resolved it to; a model-map ID must come back unchanged. */
export function modelMatches(requested: string, reported: string): boolean {
  if (requested === reported) return true;
  return ALIAS.test(requested) && reported.toLowerCase().includes(`claude-${requested}`);
}

const CREDENTIAL_ERRORS: Readonly<Record<string, AccountProblem>> = {
  authentication_failed: AccountProblem.SignedOut,
  oauth_org_not_allowed: AccountProblem.SignedOut,
  cloud_credential_error: AccountProblem.SignedOut,
  billing_error: AccountProblem.CannotBill,
  account_on_hold: AccountProblem.CannotBill,
};

/** An assistant error that is the account's, not the work's. */
export function credentialProblem(error: string | undefined): AccountProblem | null {
  return error === undefined ? null : (CREDENTIAL_ERRORS[error] ?? null);
}
```

```ts
/** How long an identity probe waits for `accountInfo()`. */
const IDENTITY_PROBE_MS = 15_000;

/** Ends the stream so the process exits; anything it throws after the abort means nothing here. */
async function drain(q: AsyncIterable<unknown>): Promise<void> {
  try {
    for await (const message of q) if (message === undefined) break;
  } catch {
    return;
  }
}

/** Claude Code started only to say who it is: no prompt, no project settings, no MCP servers, no tools. */
async function probeAccount(
  probe: AccountProbeSpec,
  opts: ClaudeAdapterOptions,
  runQuery: QueryFn,
): Promise<SeenAccount> {
  const clock = opts.clock ?? systemClock;
  const input = createChannel<SDKUserMessage>();
  const abortController = new AbortController();
  const q = runQuery({
    prompt: input,
    options: {
      cwd: probe.cwd,
      env: { ...probe.env },
      pathToClaudeCodeExecutable: opts.claudePath,
      settingSources: [],
      strictMcpConfig: true,
      permissionMode: 'default',
      canUseTool: () =>
        Promise.resolve({ behavior: 'deny', message: 'An identity probe runs no tools.' }),
      abortController,
    },
  });
  try {
    const info = await settleWithin(clock, q.accountInfo(), IDENTITY_PROBE_MS);
    if (!info)
      throw new AccountProbeError(
        `Claude Code reported no account within ${String(IDENTITY_PROBE_MS / 1_000)} s`,
      );
    return seenFrom(info);
  } finally {
    input.end();
    abortController.abort();
    void drain(q);
  }
}
```

`apps/daemon/src/accounts/start-gate.ts`:

```ts
/**
 * One start at a time per key. On a subscription account, concurrent sessions may race an OAuth refresh
 * (Claude Code issues 54443 and 61923; spike 12's refresh check is unfinished), so its starts and probes
 * queue here until the previous one reports `started` or ends.
 */
export interface StartGate {
  /** Resolves with a release once every earlier holder of `key` has released; releasing twice is harmless. */
  acquire(key: string): Promise<() => void>;
  /** How many callers wait for `key` now, the holder excluded. */
  waiting(key: string): number;
}

export function createStartGate(): StartGate {
  const tails = new Map<string, Promise<void>>();
  const queued = new Map<string, number>();
  return {
    acquire(key) {
      const before = tails.get(key) ?? Promise.resolve();
      let open: () => void = () => undefined;
      const mine = new Promise<void>((resolve) => {
        open = resolve;
      });
      const tail = before.then(() => mine);
      tails.set(key, tail);
      queued.set(key, (queued.get(key) ?? 0) + 1);
      void tail.then(() => {
        if (tails.get(key) === tail) tails.delete(key);
      });
      return before.then(() => {
        queued.set(key, (queued.get(key) ?? 1) - 1);
        let released = false;
        return () => {
          if (released) return;
          released = true;
          open();
        };
      });
    },
    // Callers whose acquire has not resolved yet; the holder's already has.
    waiting: (key) => queued.get(key) ?? 0,
  };
}
```

```ts
  prepare(account: AccountRow, projectId: ProjectId): void;
  /** Settles once every probe started so far has finished (tests). */
  idle(): Promise<void>;
}

export function createAccountPreparer(opts: {
  readonly state: StateStore;
  readonly clock: Clock;
  readonly inbox: InboxService;
  readonly adapter: Pick<SessionAdapter, 'probeAccount'>;
  readonly launcher: Pick<Launcher, 'probe'>;
  readonly startGate: StartGate;
  readonly dataDir: string;
  readonly logger: Logger;
  /** An account became ready: the scheduler looks again. */
  onReady(): void;
}): AccountPreparer {
  const running = new Map<AccountId, Promise<void>>();
  const lastTried = new Map<AccountId, number>();

  const raise = (projectId: ProjectId, card: AccountCard): void => {
    opts.inbox.flag({
      projectId,
      workstreamId: null,
      title: card.title,
      body: card.body,
      detail: card.detail,
      foldKey: card.foldKey,
      ...(card.options ? { options: card.options } : {}),
    });
  };

  async function confirmIdentity(account: AccountRow, projectId: ProjectId): Promise<void> {
    let seen: SeenAccount;
    try {
      const release = await opts.startGate.acquire(account.id);
      try {
        seen = await opts.adapter.probeAccount({
          cwd: opts.dataDir,
          env: opts.launcher.probe(account).env,
        });
      } finally {
        release();
      }
    } catch (error) {
      // Probe errors name a timeout or a missing claude, never a credential.
      raise(
        projectId,
        unreadableCard(account, error instanceof Error ? error.message : String(error)),
      );
      return;
    }
    if (!seen.email || !seen.subscriptionType) {
      raise(projectId, signInCard(account));
      return;
    }
    if (account.configDir === null) {
      // Claude Code's default directory holds the builder's current login (accounts spec §3).
      const email = seen.email;
      opts.state.write((ctx) => patchAccount(ctx, account.id, { expectedIdentity: email }));
      opts.logger.info({ accountId: account.id }, 'recorded the default account identity');
      opts.onReady();
      return;
    }
    raise(projectId, confirmCard(account, seen.email));
  }

  return {
    prepare(account, projectId) {
      const problem = unready(account);
      if (!problem || running.has(account.id)) return;
      const now = opts.clock.now().getTime();
      const last = lastTried.get(account.id);
      if (last !== undefined && now - last < PREPARE_RETRY_MS) return;
      lastTried.set(account.id, now);
      if (
        problem.problem !== AccountProblem.Unconfirmed ||
        account.kind !== AccountKind.ClaudeSubscription
      ) {
        raise(projectId, secretCard(account));
        return;
      }
      const job = confirmIdentity(account, projectId)
        .catch((error: unknown) => {
          opts.logger.error(
            { accountId: account.id, err: String(error) },
            'preparing the account failed',
          );
        })
        .finally(() => running.delete(account.id));
      running.set(account.id, job);
    },
    idle: async () => {
      await Promise.all([...running.values()]);
    },
  };
}
```

```ts
import { realpathSync } from 'node:fs';
import { homedir } from 'node:os';
import { basename, resolve } from 'node:path';
import { SECRET_VARIABLES } from '../environment';
import { isWithin } from './paths';

const KEYCHAIN = 'Keychain commands are never run by agents: 10db keeps account secrets there.';
const ENV_DUMP =
  'Printing the environment would show account credentials. Read the one variable you need, if it holds no credential.';
const secret = (name: string): string =>
  `${name} holds an account credential; agents never read it.`;

export function dataDirRefusal(dataDir: string): string {
  return `${dataDir} is 10db's data directory, which holds every account's sign-in; agents never read or write it.`;
}

/** `security` in any form, and AppleScript that names the Keychain. */
export function keychainRefusal(command: readonly string[]): string | null {
  const [head = '', ...args] = command;
  if (head === 'security') return KEYCHAIN;
  if (head === 'osascript' && args.some((a) => /keychain|\bsecurity\b/i.test(a))) return KEYCHAIN;
  return null;
}

const isSecretName = (word: string): boolean => SECRET_VARIABLES.includes(word.split('=')[0] ?? '');

/**
 * Commands that print the environment, or one credential in it. `written` is the segment's words as
 * written (with `env` and assignments); `command` is what runs once those prefixes are stripped.
 */
export function envDumpRefusal(
  written: readonly string[],
  command: readonly string[],
): string | null {
  if (command.length === 0 && written.some((w) => basename(w) === 'env')) return ENV_DUMP;
  const [head = '', ...args] = command;
  const names = args.filter((a) => !a.startsWith('-'));
  switch (head) {
    case 'printenv':
      return ENV_DUMP;
    case 'set':
      return args.length === 0 ? ENV_DUMP : null;
    case 'export':
    case 'declare':
    case 'typeset':
    case 'readonly': {
      const credential = names.find(isSecretName);
      if (credential) return secret(credential.split('=')[0] ?? credential);
      return names.length === 0 ? ENV_DUMP : null;
    }
    case 'compgen':
      return args.some((a) => /^-[a-zA-Z]*[ev]/.test(a)) ? ENV_DUMP : null;
    case 'ps':
      // macOS ps prints each process's environment with -e or -E, or `e` in a BSD-style word.
      return args.some((a) => (a.startsWith('-') ? /^-[a-zA-Z]*[eE]/.test(a) : /e/.test(a)))
        ? ENV_DUMP
        : null;
    default:
      return null;
  }
}

/** `$NAME` or `${NAME…}` of a credential variable anywhere in the segment. */
export function secretReferenceRefusal(raw: string): string | null {
  const name = SECRET_VARIABLES.find((n) => new RegExp(`\\$\\{?${n}(?![A-Za-z0-9_])`).test(raw));
  return name ? secret(name) : null;
}

function expandHome(text: string): string {
  const home = homedir();
  return text
    .replaceAll('${HOME}', home)
    .replaceAll('$HOME', home)
    .replace(/(^|[\s=:])~(?=\/|$)/gm, `$1${home}`);
}

/** The data directory as given and as the file system resolves it (a temp directory is often a link). */
function forms(dataDir: string): string[] {
  try {
    return [dataDir, realpathSync.native(dataDir)];
  } catch {
    return [dataDir];
  }
}

/** Whether text names the data directory however it is quoted or escaped: `\ `, quotes, `~` or `$HOME`. */
export function mentionsDataDir(text: string, dataDir: string): boolean {
  const plain = expandHome(text.replaceAll('\\ ', ' ').replace(/["']/g, '')).toLowerCase();
  return forms(dataDir).some((d) => plain.includes(d.toLowerCase()));
}

/** A path, or a word that may be one, landing under the data directory from the repo. */
export function pathRefusal(value: string, repoPath: string, dataDir: string): boolean {
  if (value.startsWith('-')) return false;
  return isWithin(dataDir, resolve(repoPath, expandHome(value))) || mentionsDataDir(value, dataDir);
}
```

```ts
export interface AccountService {
  list(): AccountDto[];
  create(input: AccountConfig): AccountCreatedDto;
  patch(id: AccountId, patch: AccountPatch): AccountDto;
  archive(id: AccountId): AccountDto;
  setSecret(id: AccountId, input: AccountSecretInput): AccountDto;

  identity(id: AccountId): Promise<AccountIdentityDto>;

/** The directory and every level 10db made above it: readable by the builder only (accounts spec §4). */
function makePrivate(root: string, dir: string): void {
  mkdirSync(dir, { recursive: true, mode: 0o700 });
  // mkdir's mode passes through the umask, so each level is set explicitly.
  for (const path of [root, dirname(dir), dir]) chmodSync(path, 0o700);
}

const nothingSeen = (id: AccountId): Omit<AccountIdentityDto, 'refusal'> => ({
  accountId: id,
  email: null,
  organization: null,
  apiProvider: null,
  apiKeySource: null,
  tokenSource: null,
  subscription: false,
});

export function createAccountService(deps: {
  readonly state: StateStore;
  readonly clock: Clock;
  readonly dataDir: string;
  readonly keychain: Keychain;
  readonly launcher: Pick<Launcher, 'probe'>;
  readonly adapter: Pick<SessionAdapter, 'probeAccount'>;
  readonly startGate: StartGate;
  readonly runtime: Pick<AccountRuntime, 'saved'>;
  /** An account changed: the scheduler looks again. */
  onSaved(): void;
}): AccountService {
  const db = deps.state.db;
  const root = join(deps.dataDir, 'accounts');
  const saved = (id: AccountId): void => {
    deps.runtime.saved(id);
    deps.onSaved();
  };
  const signInOf = (account: AccountDto): AccountSignInDto | null =>
    account.kind === AccountKind.ClaudeSubscription
      ? {
          accountId: account.id,
          configDir: account.configDir,
          command: signInCommand(account.configDir),
        }
      : null;

  return {
    list: () => listAccounts(db, { includeArchived: true }),
    create(input) {
      const account = deps.state.write((ctx) => {
        const created = insertAccount(ctx, input, {
          configDirFor: (id) => join(root, id, 'claude'),
        });
        // Inside the transaction: a directory that can't be made leaves no row behind.
        if (created.configDir !== null) makePrivate(root, created.configDir);
        return created;
      });
      return { account, signIn: signInOf(account) };
    },
    patch(id, patch) {
      const account = deps.state.write((ctx) => patchAccount(ctx, id, patch));
      saved(id);
      return account;
    },
    archive: (id) => deps.state.write((ctx) => archiveAccount(ctx, id)),
    setSecret(id, input) {
      const { secret } = AccountSecretInput.parse(input);
      const row = getAccountRow(db, id);
      if (row.archived) throw new ConflictError(`Account "${row.label}" is archived`);
      if (row.secretRef === null) throw new InvalidError(`Account "${row.label}" takes no secret`);
      try {
        deps.keychain.write(row.secretRef, secret);
      } catch (error) {
        // Keychain messages name the item and the status, never the value.
        if (error instanceof KeychainError) throw new ConflictError(error.message);
        throw error;
      }
      const account = deps.state.write((ctx) =>
        recordAccountSecret(ctx, id, secretFingerprint(secret)),
      );
      saved(id);
      return account;
    },
    signIn(id) {
      const signIn = signInOf(getAccount(db, id));
      if (!signIn)
        throw new InvalidError('Only a Claude subscription account signs in with claude /login');
      return signIn;
    },
    async identity(id) {
      const row = getAccountRow(db, id);
      let launch;
      try {
        launch = deps.launcher.probe(row);
      } catch (error) {
        if (!(error instanceof AccountLaunchError)) throw error;
        return {
          ...nothingSeen(id),
          refusal: { problem: error.problem, message: error.message, seenIdentity: null },
        };
      }
      let seen: SeenAccount;
      try {
        const release =
          row.kind === AccountKind.ClaudeSubscription
            ? await deps.startGate.acquire(id)
            : () => undefined;
        try {
          seen = await deps.adapter.probeAccount({ cwd: deps.dataDir, env: launch.env });
        } finally {
          release();
        }
      } catch (error) {
        throw new ConflictError(
          `Couldn't read the account ${row.label}: ${error instanceof Error ? error.message : String(error)}`,
        );
      }
      const unconfirmed =
        row.kind === AccountKind.ClaudeSubscription && row.expectedIdentity === null
          ? {
              problem: AccountProblem.Unconfirmed,
              message: `Account "${row.label}" has no confirmed identity yet`,
              seenIdentity: seen.email ?? null,
            }
          : null;
      return {
        accountId: id,
        email: seen.email ?? null,
        organization: seen.organization ?? null,
        apiProvider: seen.apiProvider ?? null,
        apiKeySource: seen.apiKeySource ?? null,
        tokenSource: seen.tokenSource ?? null,
        subscription: Boolean(seen.subscriptionType),
        refusal: checkAccount(launch.expect, seen) ?? unconfirmed,
      };
    },
    usage(id, month) {
      getAccountRow(db, id);
      const window = month === null ? monthOf(deps.clock.now()) : monthWindow(month);
      return accountUsage(db, id, usageWindow(window));
    },
  };
}
```
