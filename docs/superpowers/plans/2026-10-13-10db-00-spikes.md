# 10db Spikes (pre-M1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **For this plan, run inline (superpowers:executing-plans).** Spike results need judgment: a probe that half-works must be read, not just scored. Use a subagent only for the optional spike 10.

**Goal:** Prove or disprove the Agent SDK assumptions that M1 is built on, on the real `claude` binary and the
builder's Max subscription, and record each result in `docs/architecture/research/`.

**Architecture:** A standalone TypeScript package at `spikes/agent-sdk/`. It sits outside the future pnpm
workspace, and M0 excludes `spikes/` from lint and knip. Shared helpers build a clean child environment, resolve
the installed `claude`, create a throwaway git repo and drive `query()`. Each spike is one probe script. It
prints `PASS`, `FAIL`, `PARTIAL` or `INFO` lines, writes evidence JSON to `spikes/agent-sdk/out/`, and exits
non-zero on failure. Each task ends with a research note.

**Tech Stack:** Node (target 26, any ≥ 24 runs the spikes), pnpm, `tsx`, `@anthropic-ai/claude-agent-sdk`
0.3.299, `@modelcontextprotocol/sdk` 1.32.1, `zod` 4.6.7, macOS `caffeinate` and `pmset`.

**Spec:** `docs/superpowers/specs/2026-10-13-10db-factory-loop-design.md` (§14 spikes; §2 decisions 2, 3, 5, 18;
§3 environment and Agent SDK settings; §5.3 and §5.4; §6; §7).

**Scope:** spec §14 spikes 1, 2, 3, 4, 5, 6, 7 and 9, plus 10 as an optional timeboxed task.
- **Spike 8** (Node single-executable sidecar inside Tauri) needs M0's Tauri shell, so it is the first task of
  the M1b plan.
- **Spike 11** (Rust toolchain and the first Tauri 2 window) is folded into M0.

## Global Constraints

- **Billing safety.** These spikes must run on the Max subscription through the user's own logged-in `claude`.
  The builder's Claude Code session may be Bedrock-billed, so its environment carries `CLAUDE_CODE_USE_BEDROCK`,
  `AWS_*` and possibly `ANTHROPIC_*`. The child env is therefore built from an allowlist only: `HOME`, `PATH`,
  `USER`, `SHELL`, `LANG`, `TERM`, `TMPDIR`, plus the one key 10db sets itself, `CLAUDE_AGENT_SDK_CLIENT_APP`.
  Anything else is never forwarded, in particular `CLAUDE_CODE_*`, `CLAUDE_AGENT_*` (apart from that key),
  `ANTHROPIC_*`, `AWS_*` and `CLAUDECODE`.
- **Each probe proves its billing route with an allowlist.** It reads `accountInfo()` (with a 10 s timeout) and the
  `init` message. It throws unless all three hold:
  - `apiKeySource` is `none`;
  - `apiProvider` is `firstParty`;
  - `subscriptionType` is non-empty.

  `none` alone is not enough, because a Bedrock session also reports `none`. A Console API-key login
  (`/login managed key`) reports `firstParty`, so the key-source check is what rules it out. The probe logs
  `tokenSource` and never logs `email` or `organization`.
- **Use the installed binary:** `pathToClaudeCodeExecutable` is the output of `which claude`, resolved when a
  probe starts (`src/claude.ts`). This plan was written against Claude Code 2.1.299.
- **`settingSources: ['project']`** in every probe, the same value M1b uses. Spike 1 adds control runs with `[]`
  and with `['project', 'local']`. Every probe sets `strictMcpConfig: true`, so claude.ai connectors and user MCP
  servers never load.
- **Spend as little quota as possible:**
  - Model `haiku`, effort `low`, tiny prompts and `maxTurns` ≤ 10.
  - A fresh throwaway repo from `mkdtemp` for every probe.
  - Spikes 1, 5 and 6 rerun on `sonnet` when haiku's behavior is what failed.
  - Every probe prints `total_cost_usd`. That figure is an estimate; it is not billed on a subscription.
- **Every probe is bounded.** `baseOptions` sets a wall-clock abort of 180 s (spike 6 raises it for its hold) and
  `maxBudgetUsd: 0.5` as a runaway cap. Each conversation turn times out after 120 s.
- **Exact pins** in `spikes/agent-sdk/package.json`:

  | Package | Version |
  |---|---|
  | `@anthropic-ai/claude-agent-sdk` | 0.3.299 |
  | `@modelcontextprotocol/sdk` | 1.32.1 |

  | `@types/node` | 26.6.5 |

- **Install command** (from the repo root): `pnpm --dir spikes/agent-sdk install --ignore-workspace`.
- **No secrets and no account emails** in the notes or `out/`. The helpers never print `email`.
- **Research note template.** Every spike note uses this file name and these sections:

## Review Focus

These are the failure modes most likely to make a spike report PASS when M1 would still break. Each one has a
check in the task named in brackets.
1. **A silent billing fallback.** When the env is stripped, `claude` may fail to find the Keychain login and
   quietly use an API key or Bedrock. Expected: every probe fails loudly. [Task 1 preflight, plus `drive()` in
   every probe]
2. **Orphaned `claude` processes after an interrupt or abort.** Expected: neither the captured `claude` pid nor
   anything in its process group survives 3 seconds after the query ends, because M1 recovery fences orphans and must know whether the SDK leaves any.
   [Task 7]
3. **A canary that passes for the wrong reason.** The model might simply ignore an injected file. Expected:
   isolation is judged from deterministic SDK data, never the model's answer:
   - `getContextUsage().memoryFiles` and `init.skills` are compared with the files on disk.
   - A `settings.local.json` hook leaves a marker file only when `local` is loaded.

   [Task 2]
4. **The MCP header comes from somewhere else.** Expected: a random per-run token, `strictMcpConfig: true`, and
   the server compares the exact header value. [Task 5]
5. **The units of `resetsAt` are misread.** Seconds and milliseconds differ by 1000×, so a paused lane could
   wake 50 years late or at once. Expected: units are inferred from a live event and compared with the clock.
   [Task 9]
6. **A repo MCP tool runs without asking.** M1b passes a repo's `.mcp.json` servers through `mcpServers` with no
   allow rule, so `canUseTool` is the only gate on their tools. Expected: the callback records every
   `mcp__<server>__<tool>` call for an HTTP and a stdio server, and the stdio server logs each call it receives,
   so a call that ran with no callback shows up as a server hit. [Task 5]
7. **A repo stdio server inherits the builder's login.** Claude Code merges a declared `env` over its own
   environment, which holds the subscription token or an API key. Expected: a sentinel set only in the query's
   `env` reaches a plainly declared server and never the one launched through `env -i`, whose keys are exactly
   `HOME` and `PATH`. [Task 5]

```ts
// Builds the environment for a spawned claude from an allowlist, so a Bedrock- or API-key-billed parent session
// can never switch the child's billing. 10db's env builder (M1b) follows the same rule.
const ALLOWED = ['HOME', 'PATH', 'USER', 'SHELL', 'LANG', 'TERM', 'TMPDIR'] as const;
const FORBIDDEN = /^(AWS_|ANTHROPIC_|CLAUDE_CODE_|CLAUDE_AGENT_|CLAUDECODE$)/;
const CLIENT_APP_KEY = 'CLAUDE_AGENT_SDK_CLIENT_APP';

export function buildChildEnv(source: NodeJS.ProcessEnv = process.env): Record<string, string> {
  const env: Record<string, string> = {};
  for (const key of ALLOWED) {
    const value = source[key];
    if (value !== undefined) env[key] = value;
  }
  env[CLIENT_APP_KEY] = '10db-spikes/0.0.0';
  assertCleanEnv(env);
  return env;
}

export function assertCleanEnv(env: Record<string, string>): void {
  const leaked = Object.keys(env).filter((key) => key !== CLIENT_APP_KEY && FORBIDDEN.test(key));
  if (leaked.length > 0) throw new Error(`child env leaks billing/provider vars: ${leaked.join(', ')}`);
}
```

```ts
// Resolves the user's installed claude binary; the SDK is pointed at it instead of any bundled copy.
import { execFileSync } from 'node:child_process';
import { buildChildEnv } from './env.ts';

function resolve(): { path: string; version: string } {
  const path = execFileSync('which', ['claude'], { encoding: 'utf8' }).trim();
  const version = execFileSync(path, ['--version'], { encoding: 'utf8', env: buildChildEnv() }).trim();
  return { path, version };
}

export const CLAUDE = resolve();
```

```ts
// Creates a throwaway git repo with one commit, so probes never touch a real checkout.
import { execFileSync } from 'node:child_process';
import { mkdtempSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';

export function makeFixtureRepo(files: Record<string, string> = {}): string {
  const dir = mkdtempSync(join(tmpdir(), 'tendb-spike-'));
  const git = (...args: string[]) => execFileSync('git', ['-C', dir, ...args], { stdio: 'ignore' });
  git('init', '-b', 'main');
  writeFileSync(join(dir, 'README.md'), '# spike fixture\n');
  for (const [name, content] of Object.entries(files)) writeFileSync(join(dir, name), content);
  git('add', 'README.md', ...Object.keys(files));
  git('-c', 'user.name=10db spike', '-c', 'user.email=spike@10db.invalid', 'commit', '-m', 'fixture');
  return dir;
}
```

`spikes/agent-sdk/src/report.ts`:

```ts
// Prints one line per check and writes the evidence file out/<script>.json; exits 1 on any FAIL.
import { mkdirSync, writeFileSync } from 'node:fs';
import { basename, join } from 'node:path';

type Line = { level: 'PASS' | 'FAIL' | 'PARTIAL' | 'INFO'; name: string; detail: unknown };
const lines: Line[] = [];
const outDir = join(import.meta.dirname, '..', 'out');

function emit(line: Line): void {
  lines.push(line);
  const detail = typeof line.detail === 'string' ? line.detail : JSON.stringify(line.detail);
  console.log(`${line.level} ${line.name}: ${detail}`);
}

export function check(name: string, ok: boolean, detail: string): void {
  emit({ level: ok ? 'PASS' : 'FAIL', name, detail });
}

export function partial(name: string, detail: string): void {
  emit({ level: 'PARTIAL', name, detail });
}

export function info(name: string, detail: unknown): void {
  emit({ level: 'INFO', name, detail });
}

export function finish(): never {
  mkdirSync(outDir, { recursive: true });
  const script = basename(process.argv[1] ?? 'unknown', '.ts');
  writeFileSync(join(outDir, `${script}.json`), JSON.stringify(lines, null, 2));
  const failed = lines.filter((l) => l.level === 'FAIL').length;
  console.log(failed === 0 ? `RESULT ${script}: no failures` : `RESULT ${script}: ${failed} failure(s)`);
  process.exit(failed === 0 ? 0 : 1);
}

export function outPath(file: string): string {
  mkdirSync(outDir, { recursive: true });
  return join(outDir, file);
}
```

```ts
// Shared query plumbing: the options every probe uses, a message pump that asserts subscription billing and
// records rate-limit events, and a streaming conversation for multi-turn probes.
import { appendFileSync } from 'node:fs';
import { basename } from 'node:path';
import {
  query,
  type AccountInfo,
  type Options,
  type Query,
  type SDKMessage,
  type SDKResultMessage,
  type SDKSystemMessage,
  type SDKUserMessage,
} from '@anthropic-ai/claude-agent-sdk';
import { CLAUDE } from './claude.ts';
import { buildChildEnv } from './env.ts';
import { info, outPath } from './report.ts';

export type Run = {
  messages: SDKMessage[];
  init?: SDKSystemMessage;
  result?: SDKResultMessage;
  account?: AccountInfo;
  error?: unknown;
};

const SPIKE = basename(process.argv[1] ?? 'unknown', '.ts');

export const PROBE_TIMEOUT_MS = 180_000;
export const TURN_TIMEOUT_MS = 120_000;
const ACCOUNT_TIMEOUT_MS = 10_000;

/** Aborts `controller` after `ms`; a caller's own controller is chained, not replaced. */
function withTimeout(controller: AbortController, ms: number): AbortController {
  const timer = setTimeout(() => controller.abort(new Error(`TIMEOUT: probe exceeded ${ms} ms`)), ms);
  timer.unref();
  return controller;
}

export function baseOptions(cwd: string, extra: Partial<Options> = {}, timeoutMs = PROBE_TIMEOUT_MS): Options {
  return {
    cwd,
    pathToClaudeCodeExecutable: CLAUDE.path,
    env: buildChildEnv(),
    settingSources: ['project'],
    strictMcpConfig: true,
    systemPrompt: { type: 'preset', preset: 'claude_code' },
    model: 'haiku',
    effort: 'low',
    maxTurns: 6,
    maxBudgetUsd: 0.5,
    persistSession: true,
    stderr: (data) => appendFileSync(outPath(`${SPIKE}.stderr.log`), data),
    ...extra,
    abortController: withTimeout(extra.abortController ?? new AbortController(), timeoutMs),
  };
}

/**
 * Allowlist: the subscription login reports apiKeySource 'none', apiProvider 'firstParty' and a subscription type.
 * 'none' alone is not enough (Bedrock reports it too), and firstParty alone is not enough (a Console API key
 * reports it as '/login managed key').
 */
export function assertSubscription(init: Pick<SDKSystemMessage, 'apiKeySource'> | undefined, account: AccountInfo | undefined): void {
  const provider = account?.apiProvider ?? 'unknown';
  const keySource = init?.apiKeySource ?? 'unknown';
  const subscriptionType = account?.subscriptionType ?? '';
  info('auth', { provider, apiKeySource: keySource, subscriptionType: subscriptionType || 'unknown', tokenSource: account?.tokenSource ?? 'unknown' });
  if (keySource !== 'none') throw new Error(`BILLING: apiKeySource is ${keySource}, expected none (the subscription login)`);
  if (provider !== 'firstParty') throw new Error(`BILLING: provider is ${provider}, expected firstParty`);
  if (subscriptionType === '') throw new Error('BILLING: no subscriptionType; this is not a claude.ai subscription login');
}

function accountWithin(q: Query, ms: number): Promise<AccountInfo | undefined> {
  return Promise.race([
    q.accountInfo().catch(() => undefined),
    new Promise<undefined>((resolve) => setTimeout(() => resolve(undefined), ms).unref()),
  ]);
}

function record(m: SDKMessage): void {
  if (m.type === 'rate_limit_event') {
    const row = { recordedAt: Date.now(), spike: SPIKE, info: m.rate_limit_info };
    appendFileSync(outPath('rate-limit-events.jsonl'), `${JSON.stringify(row)}\n`);
  }
  if (m.type === 'assistant' && m.error !== undefined) {
    appendFileSync(outPath('assistant-errors.jsonl'), `${JSON.stringify({ recordedAt: Date.now(), spike: SPIKE, error: m.error })}\n`);
  }
}

export async function drive(q: Query, onMessage?: (m: SDKMessage) => void | Promise<void>): Promise<Run> {
  const run: Run = { messages: [] };
  const accountP = accountWithin(q, ACCOUNT_TIMEOUT_MS);
  try {
    for await (const m of q) {
      run.messages.push(m);
      record(m);
      if (m.type === 'system' && m.subtype === 'init') {
        run.init = m;
        run.account = await accountP;
        assertSubscription(run.init, run.account);
      }
      if (m.type === 'result') {
        run.result = m;
        info('cost', { total_cost_usd: m.total_cost_usd, subtype: m.subtype, num_turns: m.num_turns });
      }
      await onMessage?.(m);
    }
  } catch (error) {
    if (error instanceof Error && error.message.startsWith('BILLING')) throw error;
    run.error = error;
  }
  return run;
}

export function runOnce(prompt: string, options: Options, onMessage?: (m: SDKMessage) => void | Promise<void>): Promise<Run> {
  return drive(query({ prompt, options }), onMessage);
}

/** A pushable prompt stream; the query stays open between turns. */
class InputQueue implements AsyncIterable<SDKUserMessage> {
  #items: SDKUserMessage[] = [];
  #wake: (() => void) | undefined;
  #closed = false;

  push(text: string): void {
    this.#items.push({ type: 'user', message: { role: 'user', content: text }, parent_tool_use_id: null } as SDKUserMessage);
    this.#wake?.();
  }

  close(): void {
    this.#closed = true;
    this.#wake?.();
  }

  async *[Symbol.asyncIterator](): AsyncIterator<SDKUserMessage> {
    for (;;) {
      const next = this.#items.shift();
      if (next) {
        yield next;
        continue;
      }
      if (this.#closed) return;
      await new Promise<void>((resolve) => (this.#wake = resolve));
    }
  }
}

export type Conversation = { q: Query; send(text: string): Promise<Run>; close(): Promise<Run> };

type Pending = { run: Run; resolve: (r: Run) => void; reject: (e: unknown) => void; timer: NodeJS.Timeout };

/**
 * A multi-turn session. `send` always settles: with the turn's result, or with `error` set if the stream ends or
 * the turn times out first (a `/compact` with no result, a hook that stops the session). A BILLING failure
 * rejects `send` and `close`, and is never left as an unhandled rejection.
 */
export function openConversation(
  options: Options,
  opts: { turnTimeoutMs?: number; onMessage?: (m: SDKMessage) => void } = {},
): Conversation {
  const turnTimeoutMs = opts.turnTimeoutMs ?? TURN_TIMEOUT_MS;
  const input = new InputQueue();
  const q = query({ prompt: input, options });
  let turn: Pending | undefined;
  let fatal: unknown;
  let ended = false;
  const take = (): Pending | undefined => {
    const t = turn;
    turn = undefined;
    if (t) clearTimeout(t.timer);
    return t;
  };
  const all = drive(q, (m) => {
    opts.onMessage?.(m);
    if (!turn) return;
    turn.run.messages.push(m);
    if (m.type === 'result') {
      const t = take();
      if (t) {
        t.run.result = m;
        t.resolve(t.run);
      }
    }
  });
  all.then(
    (run) => {
      ended = true;
      const t = take();
      if (t) t.resolve({ ...t.run, error: run.error ?? new Error('the stream ended before the turn produced a result') });
    },
    (error: unknown) => {
      ended = true;
      fatal = error;
      take()?.reject(error);
    },
  );
  return {
    q,
    send(text) {
      if (fatal !== undefined) return Promise.reject(fatal);
      if (ended) return Promise.resolve({ messages: [], error: new Error('the conversation has already ended') });
      return new Promise<Run>((resolve, reject) => {
        const pending: Pending = {
          run: { messages: [] },
          resolve,
          reject,
          timer: setTimeout(() => {
            if (turn !== pending) return;
            turn = undefined;
            resolve({ ...pending.run, error: new Error(`TIMEOUT: no result within ${turnTimeoutMs} ms`) });
          }, turnTimeoutMs),
        };
        turn = pending;
        input.push(text);
      });
    },
    async close() {
      input.close();
      return all;
    },
  };
}

/** The text of a successful result, or an empty string. */
export function resultText(run: Run): string {
  return run.result?.subtype === 'success' ? run.result.result : '';
}
```

```ts
// on the tool call. 10db uses this to attribute every MCP call to the session that made it.

import { check, finish, info } from './report.ts';

const token = randomUUID();
const seen: { method: string; path: string; auth: string | null; rpc: string }[] = [];

function toWebRequest(req: IncomingMessage, body: Buffer): Request {
  const headers = new Headers();
  for (const [k, v] of Object.entries(req.headers)) {
    if (typeof v === 'string') headers.set(k, v);
    else if (Array.isArray(v)) headers.set(k, v.join(', '));
  }
  const hasBody = req.method !== 'GET' && req.method !== 'HEAD';
  // A Uint8Array copy: the DOM types reject a Node Buffer as a request body.
  return new Request(`http://127.0.0.1${req.url ?? '/'}`, { method: req.method ?? 'GET', headers, ...(hasBody ? { body: new Uint8Array(body) } : {}) });
}

const server = createServer(async (req, res) => {
  const chunks: Buffer[] = [];
  for await (const chunk of req) chunks.push(chunk as Buffer);
  const body = Buffer.concat(chunks);
  const auth = req.headers.authorization ?? null;
  let rpc = '';
  try {
    rpc = String((JSON.parse(body.toString('utf8') || '{}') as { method?: string }).method ?? '');
  } catch {
    rpc = 'unparsed';
  }
  seen.push({ method: req.method ?? '', path: req.url ?? '', auth: auth === `Bearer ${token}` ? 'match' : auth === null ? null : 'mismatch', rpc });

  const mcp = new McpServer({ name: '10db-spike', version: '0.0.0' });

    content: [{ type: 'text', text: `WHOAMI-OK auth=${auth === `Bearer ${token}` ? 'match' : 'mismatch'}` }],
  }));
  const transport = new WebStandardStreamableHTTPServerTransport({ sessionIdGenerator: undefined, enableJsonResponse: true });
  await mcp.connect(transport);
  const response = await transport.handleRequest(toWebRequest(req, body));
  res.writeHead(response.status, Object.fromEntries(response.headers));
  res.end(Buffer.from(await response.arrayBuffer()));
});
await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve));
const port = (server.address() as AddressInfo).port;
```

```ts
  record({ event: 'call', text });
  return { content: [{ type: 'text', text: `ECHO-OK ${text}` }] };
});
await mcp.connect(new StdioServerTransport());
```

```ts
// Spike 6: three ways to wait for a human on AskUserQuestion.
//   deny-interrupt: deny with interrupt:true, let the session end, resume later with the answer as a prompt.
//   abort:          abort the query via AbortController, then resume the same way.
//   hold:           keep the canUseTool promise pending for HOLD_MS (the spec's 10-minute wait), then answer.
// The content canary TANGERINE appears only in the original task, so only a resume that really reloaded the
// transcript can write it. Orphans are checked by the captured claude pid and its process group, not by
// direct children (grandchildren reparent to launchd).
import { execFileSync, spawn } from 'node:child_process';
import { existsSync, readdirSync, readFileSync } from 'node:fs';
import { homedir } from 'node:os';
import { join } from 'node:path';
import { setTimeout as sleep } from 'node:timers/promises';
import type { CanUseTool, Options } from '@anthropic-ai/claude-agent-sdk';
import { makeFixtureRepo } from './fixture-repo.ts';
import { check, finish, info, partial } from './report.ts';
import { baseOptions, PROBE_TIMEOUT_MS, runOnce } from './session.ts';

const HOLD_MS = Number(process.env['HOLD_MS'] ?? 600_000);
const RESUME_GAP_MS = Number(process.env['RESUME_GAP_MS'] ?? 3_000);
const MODEL = process.env['SPIKE_MODEL'] ?? 'haiku';
const TASK =
  'Use the AskUserQuestion tool to ask me ONE question with two options: name the new file alpha.txt or ' +
  'beta.txt. Then create the chosen file with the Write tool; its entire content must be the word TANGERINE. ' +
  'Then reply DONE.';
type Question = { question: string; options: { label: string }[] };

const allowAll: CanUseTool = async (_tool, input) => ({ behavior: 'allow', updatedInput: input });

/** Spawns claude in its own process group and records the pid, so orphans can be checked precisely. */
function trackedSpawn(pids: number[]): NonNullable<Options['spawnClaudeCodeProcess']> {
  return (o) => {
    const child = spawn(o.command, o.args, { cwd: o.cwd, env: o.env, stdio: ['pipe', 'pipe', 'pipe'], detached: true });
    if (child.pid !== undefined) pids.push(child.pid);
    o.signal.addEventListener('abort', () => child.kill('SIGTERM'), { once: true });
    return child;
  };
}

function alive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch {
    return false;
  }
}

function groupMembers(pgid: number): string[] {
  try {
    return execFileSync('pgrep', ['-g', String(pgid)], { encoding: 'utf8' }).trim().split('\n').filter(Boolean);
  } catch {
    return [];
  }
}

function transcriptExists(sessionId: string): boolean {
  const root = join(homedir(), '.claude', 'projects');
  return existsSync(root) && readdirSync(root).some((dir) => existsSync(join(root, dir, `${sessionId}.jsonl`)));
}

const content = (repo: string, file: string): string => (existsSync(join(repo, file)) ? readFileSync(join(repo, file), 'utf8').trim() : '');

async function parkThenResume(variant: 'deny-interrupt' | 'abort'): Promise<void> {
  const repo = makeFixtureRepo();
  const controller = new AbortController();
  const pids: number[] = [];
  let question = '';
  const park: CanUseTool = async (tool, input) => {
    if (tool !== 'AskUserQuestion') return { behavior: 'allow', updatedInput: input };
    question = (input['questions'] as Question[])[0]?.question ?? '';
    if (variant === 'abort') controller.abort();
    return { behavior: 'deny', message: 'PARKED: a human will answer later. Stop now and wait.', interrupt: true };
  };
  const first = await runOnce(TASK, baseOptions(repo, { model: MODEL, canUseTool: park, abortController: controller, maxTurns: 6, spawnClaudeCodeProcess: trackedSpawn(pids) }));
  const sessionId = first.init?.session_id ?? '';
  info(`${variant}: first run ended`, { result: first.result?.subtype ?? null, error: String(first.error ?? 'none'), sessionId, pids });
  await sleep(3000);
  const survivors = pids.filter(alive);
  const group = pids.flatMap(groupMembers);
  check(`${variant}: claude pid gone 3s after the query ended`, pids.length > 0 && survivors.length === 0, JSON.stringify({ pids, survivors }));
  check(`${variant}: no process left in claude's group`, group.length === 0, JSON.stringify(group));
  check(`${variant}: transcript is on disk`, sessionId !== '' && transcriptExists(sessionId), sessionId);

  await sleep(RESUME_GAP_MS);
  const resumed = await runOnce(
    `The human has answered your earlier question ("${question}"): beta.txt. Continue the task.`,
    baseOptions(repo, { model: MODEL, resume: sessionId, canUseTool: allowAll, maxTurns: 6 }),
  );
  info(`${variant}: resumed session id`, { original: sessionId, resumed: resumed.init?.session_id ?? null, gapMs: RESUME_GAP_MS });
  check(`${variant}: resumed run completed the task from the transcript`, content(repo, 'beta.txt') === 'TANGERINE', `beta.txt = ${JSON.stringify(content(repo, 'beta.txt'))}`);
}

await parkThenResume('deny-interrupt');
await parkThenResume('abort');

{
  const repo = makeFixtureRepo();
  let heldMs = 0;
  let abortedDuringHold = false;
  const hold: CanUseTool = async (tool, input, { signal }) => {
    if (tool !== 'AskUserQuestion') return { behavior: 'allow', updatedInput: input };
    const q = (input['questions'] as Question[])[0];
    const t0 = Date.now();
    await sleep(HOLD_MS);
    heldMs = Date.now() - t0;
    abortedDuringHold = signal.aborted;
    const pick = q?.options.find((o) => /beta/i.test(o.label))?.label ?? 'beta.txt';
    return { behavior: 'allow', updatedInput: { ...input, answers: { [q?.question ?? '']: pick } } };
  };
  // The hold outlasts the default probe timeout, so this run gets its own.
  const run = await runOnce(TASK, baseOptions(repo, { model: MODEL, canUseTool: hold, maxTurns: 6 }, HOLD_MS + PROBE_TIMEOUT_MS));
  info('hold: outcome', { heldMs, abortedDuringHold, result: run.result?.subtype ?? null, error: String(run.error ?? 'none') });
  if (abortedDuringHold) partial('hold: pending canUseTool survives the wait', `signal aborted after ${heldMs}ms`);
  else check(`hold: pending canUseTool survives ${HOLD_MS}ms and the answer lands`, content(repo, 'beta.txt') === 'TANGERINE', `held ${heldMs}ms`);
}
finish();
```

```ts
// Spike 9: `caffeinate -i -w <pid>` holds a PreventUserIdleSystemSleep assertion while <pid> lives and exits by
// itself when <pid> dies, including on SIGKILL. As in M1, the holder (standing in for the daemon) spawns
// caffeinate as its own child with its own pid, so a crashed daemon leaves an orphaned caffeinate behind; it must
// still exit.
import { execFileSync, spawn } from 'node:child_process';
import { once } from 'node:events';
import { setTimeout as sleep } from 'node:timers/promises';
import { check, finish, info } from './report.ts';

const HOLDER = `
const { spawn } = require('node:child_process');
const caf = spawn('/usr/bin/caffeinate', ['-i', '-w', String(process.pid)], { stdio: 'ignore' });
process.stdout.write(String(caf.pid) + '\\n');
setInterval(() => {}, 1 << 30);
`;

function assertionLine(cafPid: number): string | undefined {
  const out = execFileSync('pmset', ['-g', 'assertions'], { encoding: 'utf8' });
  return out.split('\n').find((l) => l.includes(`pid ${cafPid}(caffeinate)`) && l.includes('PreventUserIdleSystemSleep'));
}

function alive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch {
    return false;
  }
}

async function goneWithin(pid: number, timeoutMs: number): Promise<boolean> {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    if (!alive(pid)) return true;
    await sleep(50);
  }
  return !alive(pid);
}

for (const signal of ['SIGTERM', 'SIGKILL'] as const) {
  const holder = spawn(process.execPath, ['-e', HOLDER], { stdio: ['ignore', 'pipe', 'ignore'] });
  const [chunk] = (await once(holder.stdout, 'data')) as [Buffer];
  const cafPid = Number(chunk.toString('utf8').trim());
  await sleep(1000);
  const line = assertionLine(cafPid);
  info(`${signal}: holder and caffeinate pids`, { holder: holder.pid ?? null, caffeinate: cafPid });
  info(`${signal}: assertion line`, line?.trim() ?? null);
  check(`${signal}: assertion held while the holder lives`, line !== undefined, line ? 'present' : 'absent');
  const t0 = Date.now();
  holder.kill(signal);
  const gone = await goneWithin(cafPid, 5000);
  check(`${signal}: orphaned caffeinate exits by itself after the holder dies`, gone, `${Date.now() - t0}ms`);
  check(`${signal}: assertion released`, assertionLine(cafPid) === undefined, 'absent after exit');
  if (!gone) process.kill(cafPid, 'SIGKILL');
}
finish();
```

```ts
// Spike 7: summarizes every rate_limit_event recorded by the other probes and infers the units of resetsAt by

import { existsSync, readFileSync } from 'node:fs';
import { check, finish, info, outPath, partial } from './report.ts';
```
