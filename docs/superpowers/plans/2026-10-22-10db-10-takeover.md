# 10db Takeover ("Open in terminal") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The builder presses **Open in terminal** on a running or waiting workstream. 10db pauses its managed Claude session at a safe point, releases the lease and opens the same conversation with `claude --resume <id>` in Terminal.app or iTerm2. The builder drives it by hand, quits Claude and presses **Hand back**. 10db then reconciles git (branch, history, commits, claims) and resumes the conversation in managed mode. The session is never driven two ways at once.

**Must build on (this plan executes after both are on `main`):**

- **Batch delivery**, `docs/superpowers/plans/2026-10-21-10db-08-batch-delivery.md` (on `origin/docs/batch-delivery-design`), Tasks 1–12 merged. This plan uses its `Git.currentBranch`, `BatchDto`, `getBatch`, `transitionBatch`, `UNFINISHED_BATCH_STATES`, `shipReadiness`, the `Shipper`'s `ship`, `abandon` and `checkBatch`, `recoverBatches`, `createDeliveryHarness`, the async `Scheduler.tick()` with `Scheduler.idle()`, the branch check before every launch, and `WorkstreamDto.batchId`.
- **M2b Part A**, the local branch `feat/m2b-board-and-settings` (plan `07-m2b-board-and-settings`, Tasks 1–10) merged. Takeover is a board-card action (`views/board/task-card-menu.tsx`, `board-view.tsx`) and Settings gains a Terminal section (`views/settings/sections.ts`, `section-body.tsx`).

Task 1's first step checks both are on `main` and stops if either is not.

**Architecture:**

- **States.** `TAKEN_OVER` already exists with the edges `RUNNING → TAKEN_OVER`, `TAKEN_OVER → RECOVERING | CANCELLED`. This plan adds `HANDING_OFF → TAKEN_OVER` and `WAITING_HUMAN → TAKEN_OVER`. A workstream stores a `takeover` record (the provider session, `HEAD`, the branch, the event seq and any open error) while a terminal owns its conversation. Hand-back goes `TAKEN_OVER → RECOVERING → QUEUED` with a `resume` next action on the same conversation.
- **Safe point.** The runner gains `takeOver(id)`. A live session is sent a notice and stops at the first of: its next tool call (denied before it runs), the end of its turn, a wait on the builder, or 60 seconds (then it is interrupted). The runner then enters `TAKEN_OVER`: lease cleared, claims kept, open question and permission cards cancelled in the same write. A workstream parked on a card has no runner and moves directly. A takeover is refused while the gate runs, so no request waits on a gate; one that finds no conversation to open lapses at once and the step runs on.
- **The terminal.** The daemon writes a launcher script (`<dataDir>/takeover/<sessionId>.command`, mode 0700, no secrets) and runs `/usr/bin/open -a Terminal|iTerm <script>`. The script records its pid, `cd`s into the repo, enforces the project's billing environment (the same variables and families a managed session strips; an API key is read from the Keychain at run time), prints a banner, then runs `claude --resume <id> --model <m> --effort <e> --append-system-prompt <note>`, where the note tells the resumed conversation that 10db's tools are gone. Nothing in the Tauri shell changes: no PTY, no new plugin. A terminal session is a `sessions` row with `mode: terminal`; a monitor polls its pid every 2 seconds and records when Claude starts and exits. A closed terminal is no longer the workstream's current session. 10db never signals that process.
- **Hand back.** It is refused while Claude still runs in the terminal (checked before git is read and again inside the hand-back write), when the checkout is detached or on the wrong branch (the batch branch for work in an unfinished batch, else the branch at takeover), and when history no longer contains the takeover `HEAD`. Otherwise every commit since the takeover that no other workstream recorded is credited to this one (`commit.recorded` with `via: 'terminal'`). Committed and dirty paths go through the watcher's step-end claim check, which flags and never blocks.
- **Interactions.** One workstream per project can be taken over at a time: a second takeover is refused with the first one's name. Takeover is refused while the workstream's batch is `CUTTING` or `SHIPPING`. A taken-over workstream holds its batch open (`shipReadiness` already calls it blocked) and blocks Abandon (the batch plan's abandon already refuses `TAKEN_OVER`). It holds its claims but no lane, no lease and no provider-cap slot. Keep-awake holds while Claude runs in its terminal. The watcher watches it, and its writes inside its own claims are its own for as long as it is taken over. A daemon restart keeps it `TAKEN_OVER` and leaves the terminal alone. A human-driven terminal session is **not guarded**: no `PreToolUse` guard, no `commit` tool and no 10db MCP server. Its commits are the builder's own git commits, attributed at hand-back.
- **API and UI.** `POST /workstreams/:id/takeover`, `POST /workstreams/:id/hand-back`, `GET`/`PUT /settings/terminal`. The Factory row and the board card menu offer **Open in terminal**, **Open terminal again** and **Hand back**, with a note on the terminal's state and a confirmation that names the rules of the shared checkout. Settings gains a Terminal section (Terminal or iTerm2).

**Tech Stack:** As in M2a and the batch delivery plan. No new dependencies: the launcher is POSIX `sh`, opened with macOS `/usr/bin/open`, and the daemon reads process start times with the existing `ProcessTerminator.identify` (`/bin/ps`). The Tauri shell is unchanged.

**Spec:** `docs/superpowers/specs/2026-10-13-10db-factory-loop-design.md`. This plan implements:

## Global Constraints

Everything in M0's, M1a's, M1b's, M2a's and the batch delivery plan's Global Constraints still applies. On top of that:

- **Branch:** `feat/takeover`, cut from `main` once batch delivery (Tasks 1–12) and M2b Part A are merged. Open one PR to `main` at the end; its title is a Conventional Commit.
- **Commits:**
  - Each commit is one command that names its paths: `git add <path> … && git commit -m '…'`. Never `git add -A`, `git add .` or `git commit -a`.
  - The scope is one of `daemon`, `desktop`, `contracts`, `db`, `harness`, `repo`, `ci`, `docs`, `deps`. The subject is lowercase and the header is at most 100 characters. Use single quotes for `-m`.
  - Every message ends with this footer, after a blank line:
    ```
    Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
    Claude-Session: https://claude.ai/code/session_01KFqjacxo6Va8EyHF93n3xr
    ```
    The commit commands below pass it as two extra `-m` paragraphs.
  - Run `pnpm format` first. A failing hook leaves the paths staged: fix the cause and rerun the same line. Never `--no-verify`, `LEFTHOOK=0` or `LEFTHOOK_EXCLUDE`.
- **Generated files** are regenerated, never edited: `pnpm --filter @10db/contracts generate` after a contracts change. Task 2's schema change regenerates the migration baseline (`packages/db/AGENTS.md`); there is still no published release, so there is no new migration file. After Task 2, delete any local `.dev/data`.
- **Contracts are additive** (`packages/contracts/AGENTS.md`): new schemas, a new event type, two new workflow edges and a new nullable `WorkstreamDto.takeover`. `PROTOCOL_VERSION` stays 2.
- **The launcher holds no secret.** No environment value is ever written to the launcher, a log line, an event or the database; only variable names, the Keychain service and account names, the repo path, the provider session id, the model and the banner. The script is mode 0700 and is deleted at hand-back and cancel.
- **Every value in the launcher is quoted by `shellQuote`.** Variable names and prefixes are checked against `^[A-Za-z_][A-Za-z0-9_]*$` and `^[A-Z_]+$` before they are written.
- **A terminal session's process is never signalled** by 10db: not by recovery, shutdown, cancel or hand-back (decision T5).
- **The terminal is the test boundary.** Tests never run `/usr/bin/open`. They use `createFakeTerminal()` (Task 6), which runs the real launcher with `/bin/sh` and a stub `claude` that waits on its stdin, so pid files, process start times and exits are real. `openerWith(exec)` is tested with a scripted `exec`.
- **No `as` casts, no `!`, no `any`** except at a validated boundary with a comment (`.claude/rules/code-style.md`). Exhaustive switches over `TerminalStatus`, `TerminalApp` and `StopReason` (the runner's `settle` gains one over `StopReason`, Task 5).
- **Every write that acts on a check re-reads inside its transaction.** Takeover requests await git and the terminal check, so another request can land in between. Opening a terminal, hand-back and cancel each re-read the workstream inside their `state.write` and refuse unless it is still `TAKEN_OVER` with no terminal opening or open; the parked takeover re-reads `WAITING_HUMAN` and cancels its cards in the same write.
- **Tests** (`.claude/rules/testing.md`): red first, with the expected failure written in each step; real SQLite, real git repos and real child processes; table-driven for the refusal rules, the env plan and the launcher's environment; no sleeps (wait on `waitFor`, `waitForAsync`, `runner.idle()` or `takeover.poll()` with a deadline; the `ManualClock` drives the safe-point wait and the launch timeout). A test that pins behavior an earlier plan built proves it can fail by a stated, reverted mutation.
- **Tunable values are named constants:** `DEFAULT_RUNNER_LIMITS.takeoverWaitMs = 60_000`, `DEFAULT_TAKEOVER_LIMITS = { pollMs: 2_000, launchTimeoutMs: 60_000 }`, `TERMINAL_APP_SETTING = 'takeover.terminal_app'`, `MAX_LISTED_FILES = 200`, `SECURITY_PATH = '/usr/bin/security'`, `OPEN_PATH = '/usr/bin/open'`.
- **knip:** an `index.ts` re-exports only what another module or a test imports.
- **Comments never carry decision numbers** (`.claude/rules/code-style.md`); they cite the spec (`spec §5.4`) or say the why in words.

## Review Focus

The conditions most likely to bite a person, each with the task whose tests pin it:

1. **Two drivers at once.**
   - Case: the builder presses Hand back, Cancel or Open terminal again while Claude still runs in the terminal, or in the moment between `open` and the launcher writing its pid. Or two requests race: Open terminal again lands while Hand back reads git or Cancel checks the terminal. Or he resumes the conversation in a second tab by hand. Or he takes a second workstream over in the same project.
   - Hand back, Cancel and Open again are refused while a terminal session is opening or open, with the pid and "quit it with /exit". Each re-reads the workstream inside its write, so the request that writes second is refused and the terminal that opened stays the only driver. A second takeover in the project is refused with the first one's name (T11). A second tab the builder opens himself is outside 10db's sight; the banner and README say so.
   - Tests: Task 6 (`refuses to open it again while Claude runs in the terminal`, `refuses a second takeover in the same project, naming the first`), Task 8 (`refuses while Claude runs in the terminal, then resumes the same conversation…`, `refuses while the terminal is still opening`, `is refused while Claude runs in the terminal, then cancels…`, and the `two requests at once` table).
2. **The terminal moved the checkout.**
   - Case: `git switch -c side`, `git checkout --detach`, `git reset --hard` or a rebase below the takeover point, or (in a batch) a takeover of a parked workstream while the checkout was already off the batch branch.
   - Hand back is refused with the fix spelled out; the workstream stays `TAKEN_OVER` and nothing is lost. In a batch, the batch branch is what counts.
   - Tests: Task 8 (`handBackRefusal` table and `refuses to hand back after the terminal …` rows), Task 9 (`refuses hand back off the batch branch…`).
3. **The session never reaches a safe point, or something else happens first.**
   - Case: a tool that runs for 20 minutes; a question waiting on a card; a turn that ends; a cancel or a pause during the wait; a takeover asked for while the runner already stops for another reason; a takeover asked for while the gate runs, or before the session has begun a conversation.
   - Each ends in a defined state: `TAKEN_OVER` after at most `takeoverWaitMs`, or the other outcome wins and the takeover answers 409 naming the state. During the gate the request is refused at once, and a takeover with nothing to take over lapses at once; neither waits on the gate or spends a recovery attempt.
   - Tests: Task 5 (`takeover` describe, eight cases), Task 6 (`answers 409 when the session ends some other way first`, the `about to run its gate` refusal row).
4. **A restart or Quit while taken over.**
   - Case: `kill -9` of the daemon, the app quitting, or a reboot of 10db while Claude runs in Terminal.
   - The workstream stays `TAKEN_OVER`, its terminal session stays open, its process is not signalled, and the monitor picks it up again. If the terminal had switched branches in a batch project, the batch fails at startup and the way back works.
   - Tests: Task 9 (`keeps a taken-over workstream, its open terminal session and its process`, `restarts with the terminal off the batch branch…`).
5. **Billing leaks into the terminal.**

```ts
    async isAncestor(repo, ancestor) {
      const sha = Sha.safeParse(ancestor);
      if (!sha.success) return false;
      const args = ['merge-base', '--is-ancestor', sha.data, 'HEAD'];
      try {
        await run('git', ['-C', repo, ...args], { env: gitEnv() });
        return true;

        if (code === 1 || code === 128) return false;
        throw new GitError(args, String(error));
      }

      const args = ['diff-tree', '--no-commit-id', '--name-only', '-r', '--root'];
      return (await git(repo, [...args, '--diff-merges=first-parent', '-z', Sha.parse(sha)]))
```

```ts
import { chmodSync, mkdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import type { Effort, SessionId } from '@10db/contracts';
import { z } from 'zod';
import type { TerminalEnvPlan } from '../environment';

/** Where `security` lives on macOS; the launcher reads an API key with it when it runs. */
export const SECURITY_PATH = '/usr/bin/security';
const LAUNCHER_DIR = 'takeover';
const VARIABLE = /^[A-Za-z_][A-Za-z0-9_]*$/;
const PREFIX = /^[A-Z_]+$/;
const Pid = z.string().regex(/^\d+$/).transform(Number).pipe(z.int().positive());

/**
 * Appended to the resumed conversation's system prompt. Its transcript still lists 10db's MCP tools,
 * which a terminal session doesn't have, so its first commit would reach for them.
 */
export const TERMINAL_SYSTEM_PROMPT =
  "The builder now drives this session from a terminal, outside 10db. 10db's MCP tools (commit, write_handoff, ask_human and the rest of mcp__10db__) are unavailable here: commit with plain git, ask the builder directly, and do not write a handoff.";

/** A launcher that can't be written safely: a name or prefix the shell would read as code. */
export class LauncherError extends Error {
  override readonly name = 'LauncherError';
}

export interface LauncherPaths {
  /** A `.command` file, which Terminal and iTerm2 open by running it. */
  readonly script: string;
  /** The launcher writes its own pid here first. */
  readonly pidFile: string;
}

export function launcherPaths(dataDir: string, sessionId: SessionId): LauncherPaths {
  const dir = join(dataDir, LAUNCHER_DIR);
  return { script: join(dir, `${sessionId}.command`), pidFile: join(dir, `${sessionId}.pid`) };
}

/** One shell word whatever `value` holds: single quotes, with each `'` closed, escaped and reopened. */
export function shellQuote(value: string): string {
  return `'${value.replaceAll("'", `'\\''`)}'`;
}

export interface LauncherInput {
  readonly repoPath: string;
  readonly claudePath: string;
  readonly providerSessionId: string;
  readonly model: string;
  readonly effort: Effort;
  readonly env: TerminalEnvPlan;
  readonly pidFile: string;
  /** Lines printed before Claude starts. */
  readonly banner: readonly string[];
  /** Tests point this at a stub. */
  readonly securityPath?: string;
}

function variable(name: string): string {
  if (!VARIABLE.test(name))
    throw new LauncherError(`${JSON.stringify(name)} is not a variable name`);
  return name;
}

function prefix(value: string): string {
  if (!PREFIX.test(value))
    throw new LauncherError(`${JSON.stringify(value)} is not a variable prefix`);
  return value;
}

/**
 * The script a terminal app runs for a takeover (spec §5.4). It records its pid, enters the repo,
 * applies the project's billing environment, prints the banner and resumes the conversation with a
 * note that 10db's tools are gone. Every value is one quoted word, and the script holds no secret.
 */
export function renderLauncher(input: LauncherInput): string {
  const q = shellQuote;
  const lines = [
    '#!/bin/sh',
    '# Written by 10db for one takeover and deleted at hand-back. It holds no secrets.',
    `echo $$ > ${q(input.pidFile)}`,
    `cd ${q(input.repoPath)} || exit 1`,
    ...input.env.unset.map((name) => `unset ${variable(name)}`),
  ];
  if (input.env.unsetPrefixes.length > 0) {
    const names = `^((${input.env.unsetPrefixes.map(prefix).join('|')})[A-Za-z0-9_]*)=.*`;
    lines.push(`for name in $(env | sed -nE ${q(`s/${names}/\\1/p`)}); do unset "$name"; done`);
  }
  for (const [name, value] of Object.entries(input.env.set))
    lines.push(`export ${variable(name)}=${q(value)}`);
  if (input.env.keychainApiKey) {
    const { service, account } = input.env.keychainApiKey;
    const security = q(input.securityPath ?? SECURITY_PATH);
    lines.push(
      `ANTHROPIC_API_KEY="$(${security} find-generic-password -s ${q(service)} -a ${q(account)} -w)" || { echo '10db: could not read the API key from the Keychain.'; exit 1; }`,
      'export ANTHROPIC_API_KEY',
    );
  }
  lines.push(
    `printf '%s\\n' ${input.banner.map(q).join(' ')}`,
    [
      q(input.claudePath),
      '--resume',
      q(input.providerSessionId),
      '--model',
      q(input.model),
      '--effort',
      q(input.effort),
      '--append-system-prompt',
      q(TERMINAL_SYSTEM_PROMPT),
    ].join(' '),
    'status=$?',
    `printf '\\n10db: Claude exited with status %s. Press Hand back in 10db when you are done.\\n' "$status"`,
  );
  return `${lines.join('\n')}\n`;
}

/** Writes the script readable and runnable by its owner only. */
export function writeLauncher(paths: LauncherPaths, text: string): void {
  mkdirSync(dirname(paths.script), { recursive: true, mode: 0o700 });
  writeFileSync(paths.script, text, { mode: 0o700 });
  chmodSync(paths.script, 0o700);
}

export function removeLauncher(paths: LauncherPaths): void {
  rmSync(paths.script, { force: true });
  rmSync(paths.pidFile, { force: true });
}

/** The pid the launcher wrote, or null before it ran or when the file holds anything else. */
export function readLauncherPid(paths: LauncherPaths): number | null {
  let text: string;
  try {
    text = readFileSync(paths.pidFile, 'utf8');
  } catch {
    return null;
  }
  const parsed = Pid.safeParse(text.trim());
  return parsed.success ? parsed.data : null;
}

/** What the builder reads in the terminal before Claude starts: whose work it is and the checkout's rules. */
export function takeoverBanner(input: {
  readonly taskTitle: string;
  readonly workstreamId: string;
  readonly areas: readonly string[];
}): string[] {
  return [
    `10db: you are driving "${input.taskTitle}" (${input.workstreamId}).`,
    `10db: its claims are ${input.areas.length > 0 ? input.areas.join(', ') : 'none'}; keep your edits inside them.`,
    "10db: 10db's guard is off here. Commit with git as usual; the commits are credited to this task when you hand back.",
    "10db: other sessions may share this checkout. Don't switch branches, stash or reset.",
    '10db: when you are done, quit Claude with /exit and press Hand back in 10db.',
  ];
}
```

```ts
/**
 * Cancels the workstream's open cards inside the caller's write; `kinds` narrows it. A card folded
 * with other workstreams' questions only loses this workstream as a target. A takeover calls it in the
 * same write as its transition, so no answer lands on a card the terminal will ask again.
 */
export function cancelWorkstreamCards(
  ctx: WriteContext,
  workstreamId: WorkstreamId,
  kinds?: readonly InboxKind[],
): void {
  for (const item of openItemsForWorkstream(ctx.tx, workstreamId)) {
    if (item.state !== InboxState.Open) continue;
    if (kinds && !kinds.includes(item.kind)) continue;
    const targets = item.targets.filter((t) => t.workstreamId !== workstreamId);
    updateInboxItem(
      ctx,
      item.id,
      targets.length === 0 ? { state: InboxState.Cancelled, targets } : { targets },
    );
  }
}
```

```ts
import { spawn, type ChildProcess } from 'node:child_process';
import { chmodSync, existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { BillingMode, type TerminalApp } from '@10db/contracts';
import { buildTerminalEnvPlan, NO_SECRETS, type TerminalEnvPlan } from '../src/environment';
import { shellQuote, TerminalOpenError, type TerminalOpener } from '../src/takeover';
import { tempDir } from './fixtures';

/**
 * Stands in for Terminal.app at the opener boundary: it runs the real launcher with /bin/sh, so the
 * pid file, the process and its exit are real. `claude` is a stub that records its arguments and
 * waits on stdin; quit() ends it as /exit does.
 */
export interface FakeTerminal {
  readonly opener: TerminalOpener;
  readonly claudePath: string;
  /** Every open, oldest first. */
  readonly opened: { readonly script: string; readonly app: TerminalApp }[];
  /** The stub claude's last arguments and directory, once it has started. */
  claudeRun(): { args: string[]; cwd: string } | null;
  /** The next open fails with `message`, as `open` does when the app is missing. */
  failNext(message: string): void;
  /** The next open does nothing, as a window closed before its script ran. */
  dropNext(): void;
  /** Ends the newest terminal's claude, as /exit does, and waits for its launcher to exit. */
  quit(): Promise<void>;
  cleanup(): void;
}

export function subscriptionTerminalEnv(): TerminalEnvPlan {
  return buildTerminalEnvPlan({
    base: {},
    billingMode: BillingMode.Subscription,
    secrets: NO_SECRETS,
  });
}

export function createFakeTerminal(): FakeTerminal {
  const dir = tempDir('terminal');
  const record = join(dir.path, 'record');
  mkdirSync(record);
  const claudePath = join(dir.path, 'claude');
  writeFileSync(
    claudePath,
    [
      '#!/bin/sh',
      `pwd -P > ${shellQuote(join(record, 'cwd'))}`,
      `printf '%s\\n' "$@" > ${shellQuote(join(record, 'args'))}`,
      `: > ${shellQuote(join(record, 'ready'))}`,
      'read _line',
      '',
    ].join('\n'),
  );
  chmodSync(claudePath, 0o755);
  const opened: { script: string; app: TerminalApp }[] = [];
  const children: ChildProcess[] = [];
  let next: { readonly kind: 'fail'; readonly message: string } | { readonly kind: 'drop' } | null =
    null;
  const opener: TerminalOpener = {
    open(script, app) {
      opened.push({ script, app });
      const planned = next;
      next = null;
      if (planned?.kind === 'fail') return Promise.reject(new TerminalOpenError(planned.message));
      if (planned?.kind === 'drop') return Promise.resolve();
      const child = spawn('/bin/sh', [script], {
        env: { PATH: '/usr/bin:/bin', HOME: dir.path },
        stdio: ['pipe', 'ignore', 'ignore'],
      });
      // Closing stdin after the launcher already exited is not a failure.
      child.stdin.on('error', () => undefined);
      children.push(child);
      return Promise.resolve();
    },
  };
  return {
    opener,
    claudePath,
    opened,
    claudeRun() {
      if (!existsSync(join(record, 'ready'))) return null;
      return {
        args: readFileSync(join(record, 'args'), 'utf8').split('\n').filter(Boolean),
        cwd: readFileSync(join(record, 'cwd'), 'utf8').trim(),
      };
    },
    failNext(message) {
      next = { kind: 'fail', message };
    },
    dropNext() {
      next = { kind: 'drop' };
    },
    async quit() {
      const child = children.at(-1);
      if (!child || child.exitCode !== null || child.signalCode !== null) return;
      const exited = new Promise<void>((resolve) => {
        child.once('exit', () => {
          resolve();
        });
      });
      child.stdin?.end();
      await exited;
    },
    cleanup() {
      // End of input lets a stub claude exit too; killing only its shell would leave it waiting.
      for (const child of children) {
        child.stdin?.end();
        if (child.exitCode === null) child.kill('SIGKILL');
      }
      dir.cleanup();
    },
  };
}
```

```ts
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { TERMINAL_APP_LABELS, type TerminalApp } from '@10db/contracts';

/** macOS's `open`: hands a file to an app through LaunchServices, with no Automation permission. */
export const OPEN_PATH = '/usr/bin/open';
const OPEN_TIMEOUT_MS = 15_000;

/** The names `open -a` finds the apps by. */
const APP_NAMES: Readonly<Record<TerminalApp, string>> = { terminal: 'Terminal', iterm: 'iTerm' };

export class TerminalOpenError extends Error {
  override readonly name = 'TerminalOpenError';
}

/** Opens a launcher script in a terminal app. The boundary takeover tests replace. */
export interface TerminalOpener {
  open(script: string, app: TerminalApp): Promise<void>;
}

type OpenExec = (
  file: string,
  args: readonly string[],
  options: { readonly env: Record<string, string>; readonly timeout: number },
) => Promise<unknown>;

/** An opener over `exec`; `open` gets a bare PATH, since the app's own login shell supplies the rest. */
export function openerWith(exec: OpenExec): TerminalOpener {
  return {
    async open(script, app) {
      try {
        await exec(OPEN_PATH, ['-a', APP_NAMES[app], script], {
          env: { PATH: '/usr/bin:/bin' },
          timeout: OPEN_TIMEOUT_MS,
        });
      } catch (error) {
        const stderr =
          typeof error === 'object' && error !== null && 'stderr' in error
            ? String(error.stderr).trim()
            : '';
        throw new TerminalOpenError(
          `${TERMINAL_APP_LABELS[app]} could not be opened${stderr ? `: ${stderr.slice(0, 300)}` : ''}. Is it installed in /Applications?`,
        );
      }
    },
  };
}

const run = promisify(execFile);

export const systemOpener: TerminalOpener = openerWith((file, args, options) =>
  run(file, [...args], options),
);

/** For a daemon with nothing to open terminals with: every takeover's terminal fails to open with `why`. */
export function unavailableOpener(why: string): TerminalOpener {
  return { open: () => Promise.reject(new TerminalOpenError(why)) };
}
```

```ts
import {
  ConflictError,
  EventType,
  InboxKind,
  InvalidError,
  SessionMode,
  TAKEABLE_STATES,
  TerminalApp,
  TerminalStatus,
  WorkstreamState as S,
  type ProjectDto,
  type ProjectId,
  type SessionId,
  type TakeoverRecord,
  type TerminalSetting,
  type WorkstreamDto,
  type WorkstreamId,
} from '@10db/contracts';
import {
  activeClaims,
  endSession,
  enterTakeover,
  getAppSetting,
  getProject,
  getSession,
  getTask,
  getWorkstream,
  getWorkstreamRow,
  insertSession,
  latestEventSeq,
  latestProviderSessionId,
  listWorkstreams,
  markSessionStarted,
  patchWorkstream,
  setAppSetting,
  setSessionProcess,
  type DbReader,
  type SessionRow,
  type WorkstreamRow,
  type WriteContext,
} from '@10db/db';
import { z } from 'zod';
import type { Clock, Timer } from '../clock';
import { SessionEnvError, type TerminalEnvPlan } from '../environment';
import type { StateStore } from '../events';
import type { Git } from '../git';
import { cancelWorkstreamCards } from '../inbox';
import type { Logger } from '../log';
import { mintSessionToken } from '../mcp';
import type { ProcessTerminator } from '../recovery';
import type { Runner } from '../runner';
import {
  launcherPaths,
  readLauncherPid,
  removeLauncher,
  renderLauncher,
  takeoverBanner,
  writeLauncher,
} from './launcher';
import type { TerminalOpener } from './opener';

export const TERMINAL_APP_SETTING = 'takeover.terminal_app';

export const DEFAULT_TAKEOVER_LIMITS = {
  /** How often open terminals are checked for a started or exited Claude. */
  pollMs: 2_000,
  /** How long a terminal gets to start Claude before 10db calls it closed. */
  launchTimeoutMs: 60_000,
} as const;

/** The cards a session waits on; the terminal session asks again in its own way. */
const WAIT_KINDS: readonly InboxKind[] = [InboxKind.Question, InboxKind.Permission];
const StoredApp = z.enum(TerminalApp);

export interface TakeoverDeps {
  readonly state: StateStore;
  readonly runner: Pick<Runner, 'isRunning' | 'takeOver'>;
  readonly git: Git;
  readonly opener: TerminalOpener;
  readonly processes: Pick<ProcessTerminator, 'identify'>;
  readonly clock: Clock;
  readonly logger: Logger;
  readonly dataDir: string;
  /** The installed `claude`; null when the system check found none, which refuses every takeover. */
  readonly claudePath: string | null;
  /** The project's billing environment for a terminal; throws `SessionEnvError` when it can't be built. */
  terminalEnv(project: ProjectDto): TerminalEnvPlan;
  /** Work was queued or claims were freed: the scheduler should look again. */
  onWorkQueued(): void;
  readonly limits?: { readonly pollMs: number; readonly launchTimeoutMs: number };
}

export interface Takeover {
  /**
   * Pauses the managed session at a safe point and opens its conversation in a terminal (spec §5.4).
   * On a taken-over workstream whose terminal closed, opens it again.
   */
  takeOver(id: WorkstreamId): Promise<WorkstreamDto>;
  terminalSetting(): TerminalSetting;
  setTerminalSetting(input: TerminalSetting): TerminalSetting;
  /** Checks every taken-over terminal once: records a started Claude, closes an exited or unopened one. */
  poll(): Promise<void>;
  start(): void;
  stop(): void;
}

export function createTakeover(deps: TakeoverDeps): Takeover {
  const db = deps.state.db;
  const limits = deps.limits ?? DEFAULT_TAKEOVER_LIMITS;
  /** When an opening terminal is given up on: set when it opens, or at the first poll after a restart. */
  const launchDeadlines = new Map<SessionId, number>();
  /** The task title of a takeover on its way to a safe point, by project: one takeover per project. */
  const takingOver = new Map<ProjectId, string>();
  let timer: Timer | null = null;
  let stopped = true;

  function terminalApp(): TerminalApp {
    const parsed = StoredApp.safeParse(getAppSetting(db, TERMINAL_APP_SETTING));
    return parsed.success ? parsed.data : TerminalApp.Terminal;
  }

  function claudePath(): string {
    if (deps.claudePath === null)
      throw new InvalidError(
        'Claude Code was not found on your login PATH, so there is nothing to open the session with.',
      );
    return deps.claudePath;
  }

  function envPlan(project: ProjectDto): TerminalEnvPlan {
    try {
      return deps.terminalEnv(project);
    } catch (error) {
      if (error instanceof SessionEnvError) throw new InvalidError(error.message);
      throw error;
    }
  }

  /** The workstream's terminal session while it is opening or open; `reader` is `ctx.tx` inside a write. */
  function liveTerminal(reader: DbReader, row: WorkstreamRow): SessionRow | null {
    if (row.currentSessionId === null) return null;
    const session = getSession(reader, row.currentSessionId);
    return session.mode === SessionMode.Terminal && session.endedAt === null ? session : null;
  }

  /** The refusal for a second driver while the terminal is opening or Claude runs in it. */
  function stillOpen(session: SessionRow, then: string): ConflictError {
    if (session.pid === null)
      return new ConflictError(
        `The terminal is still opening. Quit Claude there once it starts, or wait ${String(limits.launchTimeoutMs / 1000)} s for 10db to give up on it, then ${then}.`,
      );
    return new ConflictError(
      `Claude is still running in the terminal (process ${String(session.pid)}). Quit it with /exit, then ${then}.`,
    );
  }

  /**
   * Re-reads the workstream inside a write that acts on a terminal check. Another request may have
   * opened a terminal, handed back or cancelled while this one awaited git or the check, so the write
   * goes ahead only while the workstream is still taken over with no terminal opening or open.
   */
  function stillTakenOver(
    ctx: WriteContext,
    id: WorkstreamId,
    then: string,
  ): { readonly row: WorkstreamRow; readonly record: TakeoverRecord } {
    const row = getWorkstreamRow(ctx.tx, id);
    if (row.state !== S.TakenOver || !row.takeover)
      throw new ConflictError(`The workstream is ${row.state} now, no longer taken over.`);
    const live = liveTerminal(ctx.tx, row);
    if (live) throw stillOpen(live, then);
    return { row, record: row.takeover };
  }

  function changed(ctx: WriteContext, id: WorkstreamId, terminal: TerminalStatus): void {
    ctx.emit({
      type: EventType.TakeoverChanged,
      entityType: 'workstream',
      entityId: id,
      data: { terminal },
    });
  }

  function closeTerminal(
    id: WorkstreamId,
    sessionId: SessionId,
    reason: string,
    openError: string | null,
  ): void {
    launchDeadlines.delete(sessionId);
    deps.state.write((ctx) => {
      endSession(ctx, sessionId, reason);
      const row = getWorkstreamRow(ctx.tx, id);
      patchWorkstream(ctx, id, null, {
        // A closed terminal is nobody's current session: hand-back and cancel then find none to end.
        ...(row.currentSessionId === sessionId ? { currentSessionId: null } : {}),
        ...(openError !== null && row.takeover ? { takeover: { ...row.takeover, openError } } : {}),
      });
      changed(ctx, id, TerminalStatus.Closed);
    });
  }

  /** Brings a terminal session's row up to date with its launcher's process. It never signals it. */
  async function refresh(id: WorkstreamId): Promise<void> {
    const session = liveTerminal(db, getWorkstreamRow(db, id));
    if (!session) return;
    const paths = launcherPaths(deps.dataDir, session.id);
    if (session.pid === null) {
      const pid = readLauncherPid(paths);
      if (pid === null) {
        const now = deps.clock.now().getTime();
        const deadline = launchDeadlines.get(session.id) ?? now + limits.launchTimeoutMs;
        launchDeadlines.set(session.id, deadline);
        if (now < deadline) return;
        removeLauncher(paths);
        closeTerminal(
          id,
          session.id,
          'terminal_not_opened',
          `The terminal didn't start Claude within ${String(limits.launchTimeoutMs / 1000)} s. Open it again, or hand back.`,
        );
        return;
      }
      const startedAt = await deps.processes.identify(pid);
      if (startedAt === null) {
        // Gone before 10db read its pid: Claude never started, or quit at once (say, no conversation).
        closeTerminal(
          id,
          session.id,
          'terminal_closed',
          'The terminal closed before 10db saw Claude start. Open it again to see why.',
        );
        return;
      }
      launchDeadlines.delete(session.id);
      deps.state.write((ctx) => {
        setSessionProcess(ctx, session.id, pid, startedAt);
        changed(ctx, id, TerminalStatus.Open);
      });
      return;
    }
    if ((await deps.processes.identify(session.pid)) !== session.pidStart)
      closeTerminal(id, session.id, 'terminal_closed', null);
  }

  /**
   * The session has one driver: refuses while its terminal is opening or Claude runs in it. The write
   * that follows checks again (`stillTakenOver`), since another request can land in between.
   */
  async function refuseWhileOpen(id: WorkstreamId, then: string): Promise<void> {
    await refresh(id);
    const session = liveTerminal(db, getWorkstreamRow(db, id));
    if (session) throw stillOpen(session, then);
  }

  /** One takeover per project: two terminals in one checkout would edit the same files. */
  function refuseAnotherTakeover(row: WorkstreamRow): void {
    const other =
      takingOver.get(row.projectId) ??
      listWorkstreams(db, { states: [S.TakenOver], projectId: row.projectId }).find(
        (w) => w.id !== row.id,
      )?.taskTitle;
    if (other !== undefined)
      throw new ConflictError(
        `"${other}" is already taken over in this project; hand it back or cancel it first. One terminal at a time drives a project's checkout.`,
      );
  }

  /** The conversation a takeover would resume; refuses work that can't be taken over now. */
  function takeable(row: WorkstreamRow, title: string): string {
    if (!TAKEABLE_STATES.includes(row.state))
      throw new ConflictError(
        `Only a running or waiting workstream can be opened in a terminal; "${title}" is ${row.state}.`,
      );
    // The gate runs no session, and waiting it out could hold the request for half an hour.
    if (row.nextAction.kind === 'verify')
      throw new ConflictError(
        `The gate is running for "${title}"; take it over after it finishes.`,
      );
    refuseAnotherTakeover(row);
    const providerSessionId = latestProviderSessionId(db, row.id);
    if (providerSessionId === null)
      throw new ConflictError(
        `"${title}" has not started a Claude session yet; try again in a moment.`,
      );
    return providerSessionId;
  }

  /** Starts a terminal session for a taken-over workstream and hands its launcher to the terminal app. */
  async function open(
    id: WorkstreamId,
    env: TerminalEnvPlan,
    claude: string,
  ): Promise<WorkstreamDto> {
    // Nobody holds this token, so a terminal session never reaches 10db's MCP tools.
    const { hash } = mintSessionToken();
    const opened = deps.state.write((ctx) => {
      // A hand back, a cancel or another open may have landed while this request awaited.
      const { row, record } = stillTakenOver(ctx, id, 'open it again');
      const s = insertSession(ctx, {
        workstreamId: id,
        provider: getProject(ctx.tx, row.projectId).provider,
        model: row.model,
        effort: row.effort,
        mode: SessionMode.Terminal,
        mcpTokenHash: hash,
      });
      markSessionStarted(ctx, s.id, record.providerSessionId, null);
      patchWorkstream(ctx, id, null, {
        currentSessionId: s.id,
        takeover: { ...record, openError: null },
      });
      changed(ctx, id, TerminalStatus.Launching);
      return { session: s, row, record };
    });
    const { session, row, record } = opened;
    const project = getProject(db, row.projectId);
    launchDeadlines.set(session.id, deps.clock.now().getTime() + limits.launchTimeoutMs);
    const paths = launcherPaths(deps.dataDir, session.id);
    try {
      writeLauncher(
        paths,
        renderLauncher({
          repoPath: project.repoPath,
          claudePath: claude,
          providerSessionId: record.providerSessionId,
          model: row.model,
          effort: row.effort,
          env,
          pidFile: paths.pidFile,
          banner: takeoverBanner({
            taskTitle: getTask(db, row.taskId).title,
            workstreamId: id,
            areas: activeClaims(db, id).map((c) => c.name),
          }),
        }),
      );
      await deps.opener.open(paths.script, terminalApp());
    } catch (error) {
      removeLauncher(paths);
      closeTerminal(
        id,
        session.id,
        'open_failed',
        error instanceof Error ? error.message : String(error),
      );
    }
    return getWorkstream(db, id);
  }

  async function takeOver(id: WorkstreamId): Promise<WorkstreamDto> {
    const row = getWorkstreamRow(db, id);
    const project = getProject(db, row.projectId);
    const title = getTask(db, row.taskId).title;
    if (row.state === S.TakenOver) {
      await refuseWhileOpen(id, 'open it again');
      return open(id, envPlan(project), claudePath());
    }
    // Everything that can refuse runs before the managed session is touched, with no await between the
    // check and the runner, so the state checked is the state the runner is asked to stop.
    const providerSessionId = takeable(row, title);
    const env = envPlan(project);
    const claude = claudePath();
    // Held until this takeover is settled, so a second one in the project is refused meanwhile.
    takingOver.set(row.projectId, title);
    try {
      if (deps.runner.isRunning(id)) {
        await deps.runner.takeOver(id);
      } else {
        const head = await deps.git.head(project.repoPath);
        const branch = await deps.git.currentBranch(project.repoPath);
        deps.state.write((ctx) => {
          const now = getWorkstreamRow(ctx.tx, id);
          if (now.state !== S.WaitingHuman || deps.runner.isRunning(id))
            throw new ConflictError(`"${title}" moved on to ${now.state}; try again.`);
          // In the same write as the transition, so no answer lands on a card the terminal asks again.
          cancelWorkstreamCards(ctx, id, WAIT_KINDS);
          enterTakeover(ctx, id, null, {
            providerSessionId,
            head,
            branch,
            takenAt: ctx.now,
            eventSeq: latestEventSeq(ctx.tx),
            openError: null,
          });
        });
      }
      const after = getWorkstreamRow(db, id);
      if (after.state !== S.TakenOver)
        throw new ConflictError(
          `The session was not taken over; "${title}" is ${after.state} now.`,
        );
      return await open(id, env, claude);
    } finally {
      takingOver.delete(row.projectId);
    }
  }

  async function poll(): Promise<void> {
    for (const ws of listWorkstreams(db, { states: [S.TakenOver] })) {
      try {
        await refresh(ws.id);
      } catch (error) {
        deps.logger.warn({ workstreamId: ws.id, err: String(error) }, 'terminal check failed');
      }
    }
  }

  return {
    takeOver,
    poll,
    terminalSetting: () => ({ app: terminalApp() }),
    setTerminalSetting(input) {
      deps.state.write((ctx) => {
        setAppSetting(ctx, TERMINAL_APP_SETTING, input.app);
        ctx.emit({
          type: EventType.SettingsChanged,
          entityType: 'app_setting',
          entityId: TERMINAL_APP_SETTING,
          data: { app: input.app },
        });
      });
      return { app: terminalApp() };
    },
    start() {
      if (!stopped) return;
      stopped = false;
      const loop = (): void => {
        void poll().finally(() => {
          if (!stopped) timer = deps.clock.setTimeout(loop, limits.pollMs);
        });
      };
      timer = deps.clock.setTimeout(loop, limits.pollMs);
    },
    stop() {
      stopped = true;
      timer?.cancel();
      timer = null;
    },
  };
}
```

```ts
import type { TakeoverRecord } from '@10db/contracts';

/** What hand-back reads from git and the batch before it gives the conversation back (spec §5.4). */
export interface HandBackFacts {
  readonly record: TakeoverRecord;
  readonly head: string;
  /** The checked-out branch now; null on a detached HEAD. */
  readonly branch: string | null;
  /** Whether the takeover HEAD is still in the history of HEAD. */
  readonly kept: boolean;
  /** The branch of the workstream's unfinished batch; null outside a batch. */
  readonly batchBranch: string | null;
  readonly repoPath: string;
}

const short = (sha: string): string => sha.slice(0, 8);

/** Why the checkout can't be handed back as it is, with the fix; null when it can. */
export function handBackRefusal(f: HandBackFacts): string | null {
  const expected = f.batchBranch ?? f.record.branch;
  const which = f.batchBranch === null ? '10db took the session over on' : 'the batch branch is';
  const fix = (branch: string) => `Run git switch ${branch} in ${f.repoPath}, then hand back.`;
  if (expected !== null && f.branch === null)
    return `The checkout is detached at ${short(f.head)}, but ${which} ${expected}. ${fix(expected)}`;
  if (expected !== null && f.branch !== expected)
    return `The checkout is on ${f.branch ?? 'a detached HEAD'}, but ${which} ${expected}. ${fix(expected)}`;
  if (!f.kept)
    return `${short(f.record.head)}, where you took the session over, is no longer in the history of ${f.branch ?? 'HEAD'}: a reset, rebase or amend dropped commits. Restore them (git reflog shows them) and hand back, or cancel the workstream.`;
  return null;
}

/** The commits since the takeover that other workstreams didn't record through the commit tool. */
export function creditedCommits(
  all: readonly string[],
  recordedByOthers: ReadonlySet<string>,
): string[] {
  return all.filter((sha) => !recordedByOthers.has(sha));
}

/** Why managed mode resumes; the resume prompt quotes it to the agent. */
export function handBackReason(commits: number): string {
  const theirs =
    commits === 0 ? '' : `, with ${String(commits)} commit${commits === 1 ? '' : 's'} of their own`;
  return `the builder drove this conversation from a terminal and handed it back${theirs}; read git status and git log before you continue, and leave their changes in place`;
}
```

```ts
async function handBack(id: WorkstreamId): Promise<WorkstreamDto> {
  const row = getWorkstreamRow(db, id);
  const record = row.takeover;
  if (row.state !== S.TakenOver || !record)
    throw new ConflictError('Only a taken-over workstream can be handed back.');
  await refuseWhileOpen(id, 'hand back');
  const repo = getProject(db, row.projectId).repoPath;
  const [head, branch, kept] = await Promise.all([
    deps.git.head(repo),
    deps.git.currentBranch(repo),
    deps.git.isAncestor(repo, record.head),
  ]);
  const refusal = handBackRefusal({
    record,
    head,
    branch,
    kept,
    batchBranch: null,
    repoPath: repo,
  });
  if (refusal) throw new ConflictError(refusal);
  const commits = creditedCommits(
    await deps.git.commitsSince(repo, record.head),
    commitShasRecordedAfter(db, record.eventSeq, id),
  );
  const files = await Promise.all(
    commits.map(async (sha) => ({ sha, paths: await deps.git.commitFiles(repo, sha) })),
  );
  const dirty = (await deps.git.status(repo)).map((s) => s.path);
  deps.state.write((ctx) => {
    // A terminal opened again, or a cancel, may have landed while git was read. No session is ended
    // here: a closed terminal ended its own and is no longer the current session.
    stillTakenOver(ctx, id, 'hand back');
    for (const { sha, paths } of files)
      ctx.emit({
        type: EventType.CommitRecorded,
        entityType: 'workstream',
        entityId: id,
        data: { sha, paths, alreadyCommitted: false, via: 'terminal' },
      });
    ctx.emit({
      type: EventType.RecoveryStep,
      entityType: 'workstream',
      entityId: id,
      data: {
        step: 'handed_back',
        head,
        branch,
        commits,
        dirtyFiles: dirty.slice(0, MAX_LISTED_FILES),
      },
    });
    transitionWorkstream(ctx, id, {
      to: S.Recovering,
      fence: null,
      reason: 'handed back from the terminal',
    });
    transitionWorkstream(ctx, id, {
      to: S.Queued,
      fence: null,
      patch: {
        takeover: null,
        currentSessionId: null,
        nextAction: {
          kind: 'resume',
          providerSessionId: record.providerSessionId,
          reason: handBackReason(commits.length),
        },
      },
      reason: 'handed back from the terminal',
    });
  });
  removeLaunchers(id);
  if (deps.reviewWrites) {
    try {
      await deps.reviewWrites(
        id,
        files.flatMap((f) => f.paths),
      );
    } catch (error) {
      deps.logger.warn({ workstreamId: id, err: String(error) }, 'hand-back claim check failed');
    }
  }
  deps.onWorkQueued();
  return getWorkstream(db, id);
}

async function cancel(id: WorkstreamId): Promise<WorkstreamDto> {
  if (getWorkstreamRow(db, id).state !== S.TakenOver)
    throw new ConflictError('Only a taken-over workstream is cancelled here.');
  await refuseWhileOpen(id, 'cancel');
  deps.state.write((ctx) => {
    // A terminal opened again may have landed while the terminal was checked.
    stillTakenOver(ctx, id, 'cancel');
    cancelWorkstreamCards(ctx, id);
    transitionWorkstream(ctx, id, {
      to: S.Cancelled,
      fence: null,
      patch: { takeover: null, currentSessionId: null },
      reason: 'cancelled by the builder',
    });
    releaseClaims(ctx, id);
    clearLease(ctx, id);
  });
  removeLaunchers(id);
  // Its claims are free: queued work in those areas can launch.
  deps.onWorkQueued();
  return getWorkstream(db, id);
}
```

```ts
import {
  TAKEABLE_STATES,
  TerminalStatus,
  WorkstreamState,
  type WorkstreamDto,
} from '@10db/contracts';

export interface TakeoverActions {
  /** Open managed work in a terminal, or open a taken-over one's closed terminal again. */
  readonly open: 'take_over' | 'reopen' | null;
  /** Offered while taken over; disabled while the terminal is opening or Claude runs in it. */
  readonly handBack: 'enabled' | 'disabled' | null;
  /** One line about the terminal, for the Factory row and the board card. */
  readonly note: string | null;
}

export const OPEN_LABELS: Readonly<Record<'take_over' | 'reopen', string>> = {
  take_over: 'Open in terminal',
  reopen: 'Open terminal again',
};

const NONE: TakeoverActions = { open: null, handBack: null, note: null };

/** What the builder can do about a workstream and its terminal (spec §5.4, §10). */
export function takeoverActions(ws: Pick<WorkstreamDto, 'state' | 'takeover'>): TakeoverActions {
  if (TAKEABLE_STATES.includes(ws.state)) return { ...NONE, open: 'take_over' };
  if (ws.state !== WorkstreamState.TakenOver || !ws.takeover) return NONE;
  switch (ws.takeover.terminal) {
    case TerminalStatus.Launching:
      return { open: null, handBack: 'disabled', note: 'Opening the terminal…' };
    case TerminalStatus.Open:
      return {
        open: null,
        handBack: 'disabled',
        note: `Claude is running in the terminal${ws.takeover.terminalPid === null ? '' : ` (process ${String(ws.takeover.terminalPid)})`}. Quit it, then hand back.`,
      };
    case TerminalStatus.Closed:
      return {
        open: 'reopen',
        handBack: 'enabled',
        note: ws.takeover.openError ?? 'The terminal is closed. Hand back when you are done.',
      };
  }
}
```

```ts
import { TerminalApp, type WorkstreamDto, type WorkstreamId } from '@10db/contracts';
import { useState } from 'react';
import { useHandBack, useTakeOver, useTerminalSetting } from '../../daemon/queries';
import { takeoverActions } from './takeover-actions';
import type { TakeoverModalProps } from './takeover-modal';

/** Takeover and hand-back for a view: a confirmation before the first takeover, none to reopen. */
export function useTakeoverFlow() {
  const takeOver = useTakeOver();
  const handBack = useHandBack();
  const setting = useTerminalSetting();
  const [confirming, setConfirming] = useState<WorkstreamDto | null>(null);
  const close = (): void => {
    setConfirming(null);
    takeOver.reset();
  };
  const modal: TakeoverModalProps = {
    workstream: confirming,
    app: setting.data?.app ?? TerminalApp.Terminal,
    loading: takeOver.isPending,
    error: confirming ? takeOver.error : null,
    onClose: close,
    onConfirm: () => {
      if (confirming) takeOver.mutate(confirming.id, { onSuccess: close });
    },
  };
  return {
    open(ws: WorkstreamDto): void {
      if (takeoverActions(ws).open === 'reopen') takeOver.mutate(ws.id);
      else setConfirming(ws);
    },
    handBack(ws: WorkstreamDto): void {
      handBack.mutate(ws.id);
    },
    busy: (id: WorkstreamId): boolean =>
      (takeOver.isPending && takeOver.variables === id) ||
      (handBack.isPending && handBack.variables === id),
    error: (confirming ? null : takeOver.error) ?? handBack.error,
    modal,
  };
}

export type TakeoverFlow = ReturnType<typeof useTakeoverFlow>;
```
