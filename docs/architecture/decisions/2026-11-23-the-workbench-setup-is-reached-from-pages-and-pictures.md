# The Workbench setup is reached from Settings › Pages and Pictures and the start page's Review line

- **Date:** 2026-11-23
- **Amends:** `2026-11-10-the-workbench-setup-rebuilds-the-areas-for-one-apply.md`

## Decision

The setup (suggested settings, the branch note and Rebuild Areas) is opened from Review Suggestions in
Settings › This Project › Pages and Pictures, badged with the count of suggestions, and from the start
page's "found in code · Review" line when the repository has new pages. The start page's title row no
longer carries a setup button: it carries a quiet Pages and Pictures link to those settings.

## Why

The setup is a one-time configuration of how pages are found and pictured, which is what Pages and Pictures
holds; the start page is for starting passes. The Review line keeps the setup one click from the picker
whenever it has new pages to offer, and the settings page keeps it reachable when it only has settings.
