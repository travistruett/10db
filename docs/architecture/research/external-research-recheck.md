## 3. Daemon surfaces

### Claude

- VERIFIED (`claude --help`): `--permission-prompts <target>`: "Who answers permission prompts with --print: "host" (the SDK host or --permission-prompt-tool) or "none" (nobody: anything that would prompt is denied automatically; the permission mode still decides everything else)". Docs (headless page): with `none`, run "doesn't consult the host"; denials appear as `permission_denied` system messages and in result `permission_denials`; requires v2.1.259+. Default value text was cut off in help output (UNKNOWN, but docs imply host is default when a host exists).
- Host protocol (VERIFIED, https://code.claude.com/docs/en/agent-sdk/typescript): host receives `{ type: "control_request", request_id, request }` for tool permission; canUseTool options include `suggestions, blockedPath, decisionReason, toolUseID, agentID, requestId`; host replies with `control_response` echoing request id carrying `PermissionResult`: `{behavior:"allow", updatedInput?, updatedPermissions?, toolUseID?}` or `{behavior:"deny", message, interrupt?, toolUseID?}`. "permission prompts don't time out" (request stays blocked). Pending requests are re-delivered on `initialize` (v2.1.268+). Requires `--input-format stream-json --output-format stream-json`. The exact raw wire shape of control_request subtype for can_use_tool: UNKNOWN (only the SDK-level types seen; TS doc chunk 200000+ not read). `--replay-user-messages` exists (help).
- Compaction events (VERIFIED): stream message `{type:"system", subtype:"compact_boundary", uuid, session_id, compact_metadata:{trigger:"manual"|"auto", pre_tokens}}`. Hooks `PreCompact` (can block via exit 2 or `decision:"block"`; input `trigger`, `custom_instructions`) and `PostCompact` (input `trigger`, `compact_summary`; cannot block); matchers `manual`/`auto`. Hook events reach stream only with `--include-hook-events` (help text, stream-json only).
- Context size: control request `getContextUsage` returns `totalTokens, maxTokens, percentage, autoCompactThreshold, isAutoCompactEnabled` (VERIFIED TS doc). CLI flag `--autocompact <auto|tokens>` (help). Per-turn `usage` fields on assistant/result messages: UNKNOWN this session (not fetched).
- Other stream events: `system/init` (with `capabilities` array), `system/api_retry`, `permission_denied`, `hook_*`, `plugin_install` (VERIFIED headless page).
- `claude agents --json` (VERIFIED local run): JSON array. Interactive entries: `pid, cwd, kind:"interactive", startedAt (ms epoch), sessionId, name, status` (seen "idle","busy"). With `--all`, background entries: `id (8-char), cwd, kind:"background", startedAt, sessionId, name, state` (seen "done"); no pid. Note the field differs: `status` (interactive) vs `state` (background). Other bg commands (help): `attach, logs, stop|kill, respawn, rm`; `--bg` prints id and returns; `--bg --resume <id>` continues same session. `claude -p` rejects `--bg` (VERIFIED headless page).
